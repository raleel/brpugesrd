# Basic Roleplaying Universal Game Engine

Документ з контентом ORC

## Подяки

Базується на системі Basic Roleplaying, створеній Стівом Перріном, Стівом Гендерсоном, Ворреном Джеймсом, Грегом Стаффордом, Сенді Петерсеном, Реєм Терні, Лінном Віллісом.

**Автори** Джейсон Дюрал та Стів Перрін

**Продюсер** Ніл Робінсон

**Додаткові подяки** Дарії Піларчик, Ріку Мейнтсу, Майклу О'Браєну та Джеффу Річарду

**Особлива подяка** Кену Сент-Андре, Кену Остіну, Вільяму Бартону, Біллу Данну, Кену Фінлейсону, Марку Л. Гамблеру, Сему Джонсону, Вільяму Джонсу, Родні Лірі, Бену Монро, Гордону Монсону, Сарі Ньютон, Сему Ширлі, Марку Моррісону та Річарду Воттсу
