## Творці

На основі системи Basic Roleplaying, створеної Стівом Перріном, Стівом Гендерсоном, Ворреном Джеймсом, Грегом Стаффордом, Сенді Пітерсеном, Реєм Терні, Лінн Вілліс.

**Автори:** Джейсон Дуралл та Стів Перрін

**Продюсер:** Ніл Робінсон

**Додаткові автори:** Дарія Піларчик, Рік Мейнтс, Майкл О’Браєн та Джефф Річард

**Окрема подяка:** Кену Сент-Андре, Кену Остіну, Вільяму Бартону, Біллу Данну, Кену Фінлейсону, Марку Л. Гамблеру, Сему Джонсону, Вільяму Джонсу, Родні Лірі, Бену Монро, Гордону Монсону, Сарі Ньютон, Сему Ширлі, Марку Моррісону та Річарду Воттсу
