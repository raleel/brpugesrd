# מנוע המשחק האוניברסלי Basic Roleplaying

מסמך תוכן ORC

## קרדיטים

מבוסס על מערכת Basic Roleplaying שנוצרה על ידי סטיב פרין, סטיב הנדרסון, וורן ג'יימס, גרג סטאפורד, סנדי פיטרסן, ריי טרני, לין ויליס

**מחברים** ג'ייסון דוראל וסטיב פרין

**מפיק** ניל רובינסון

**קרדיטים נוספים** דריה פילארצ'יק, ריק מיינטס, מייקל או'בריאן וג'ף ריצ'רד

**תודות מיוחדות** קן סנט אנדרה, קן אוסטין, ויליאם בארטון, ביל דאן, קן פינלייסון, מארק ל. גמבלר, סם ג'ונסון, ויליאם ג'ונס, רודני לירי, בן מונרו, גורדון מונסון, שרה ניוטון, סם שירלי, מארק מוריסון וריצ'רד וואטס
