ORC உள்ளடக்க ஆவணம்

## நன்றிகள்

ஸ்டீவ் பெரின், ஸ்டீவ் ஹென்டர்சன், வாரன் ஜேம்ஸ், கிரெக் ஸ்டாஃபோர்ட், சாண்டி பீட்டர்சன், ரே டர்னி, லின் வில்லிஸ் ஆகியோரால் உருவாக்கப்பட்ட அடிப்படை ரோல்பிளேயிங் (Basic Roleplaying) முறையை அடிப்படையாகக் கொண்டது.

**ஆசிரியர்கள்** ஜேசன் துரால் மற்றும் ஸ்டீவ் பெரின்

**தயாரிப்பாளர்** நீல் ராபின்சன்

**கூடுதல் நன்றிகள்** டாரியா பிலார்சிக், ரிக் மெயின்ட்ஸ், மைக்கேல் ஓ'பிரையன் மற்றும் ஜெஃப் ரிச்சர்ட்

**சிறப்பு நன்றிகள்** கென் செயின்ட் ஆண்ட்ரே, கென் ஆஸ்டின், வில்லியம் பார்டன், பில் டன், கென் ஃபின்லேசன், மார்க் எல். கேம்ப்ளர், சாம் ஜான்சன், வில்லியம் ஜோன்ஸ், ரோட்னி லியரி, பென் மன்ரோ, கார்டன் மான்சன், சாரா நியூட்டன், சாம் ஷெர்லி, மார்க் மோரிசன் மற்றும் ரிச்சர்ட் வாட்ஸ்
