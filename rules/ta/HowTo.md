## உங்கள் உள்ளடக்கத்தைச் சேர்த்தல்

### *.md கோப்புகள்

.md கோப்புகள் மார்க்-டவுன் (markdown) கோப்புகள் ஆகும். எளிய உரை ஆவணங்களுக்கு வடிவமைப்புகளைச் சேர்க்கப் பயன்படும் ஒரு இலகுரக மார்க்-அப் மொழி இது. உங்கள் உள்ளடக்கத்தின் அளவைப் பொறுத்து, உங்கள் விளையாட்டின் அனைத்துத் தகவல்களையும் ஒரே ஒரு *.md கோப்பில் வைக்கலாம், அல்லது [7thextinctionrpg.com](https://srd.7thextinctionrpg.com)-இல் நான் செய்தது போல ஒவ்வொரு அத்தியாயத்திற்கும் தனித்தனி கோப்புகளை உருவாக்கலாம். "sample.md" சில வடிவமைப்பு உதாரணங்களை வழங்குகிறது.

மார்க்-டவுன் மொழியைக் கற்றுக்கொள்வது மிகவும் எளிது. முழுமையான குறியீட்டு முறைக்கு மேலே உள்ள முன்நிபந்தனைகளின் புள்ளி 2-இல் கொடுக்கப்பட்டுள்ள இணைப்பைப் பயன்படுத்தவும்.

## உங்கள் SRD-இல் இலவச ஐகான்களைக் காட்ட Fontawesome மற்றும்/அல்லது Material Icons செருகுநிரலைப் பயன்படுத்துதல்

### Fontawesome

இலவச ஐகான்கள் மற்றும் அனிமேஷன் ஐகான்களைப் பெற Fontawesome-ஐப் பயன்படுத்தவும். சந்தா செலுத்திய பயனர்கள் Pro Icons-ஐப் பயன்படுத்தலாம்.

1. [Fontawesome](https://fontawesome.com/icons)-இல் ஐகானைக் கண்டறியவும்
2. ஐகானைத் தேர்ந்தெடுக்கவும்
3. பாப்-அப் விண்டோவில், HTML தாவலின் கீழ் " " இடையே உள்ள அனைத்தையும் நகலெடுக்கவும்

```EXAMPLE
<i class="fa-solid fa-dice-d20"></i>
```

4. நகலெடுக்கப்பட்ட உரையை `:` இடையே இடைவெளி இல்லாமல் வைக்கவும்

```EXAMPLE
fa-solid fa-dice-d20
```

### Material Icons

மேலும் பல இலவச ஐகான்களுக்கு Material Icons-ஐப் பயன்படுத்தவும்

1. [Material Icons](https://fonts.google.com/icons)-இல் ஐகான்களைக் கண்டறியவும்
2. வெப் ஸ்பான் (web span) இணைப்பை நகலெடுத்து உங்கள் மார்க்-டவுன் கோப்புகளில் நேரடியாகச் செருகவும்

```markup
<span class="material-icons">face</span>
```
