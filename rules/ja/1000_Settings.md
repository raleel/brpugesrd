# 10. セッティング

本章では、冒険の舞台となる時代や場所である「セッティング」について解説する。通常、セッティングはそのジャンルを指す。西部劇、SF、テクノスリラー、剣と魔法（ソード・アンド・サンダル）、ハイファンタジーなどがその代表例である。また、本章には忠誠、情熱、正気度に関するオプションルールも含まれている。

## セッティングの作成

『ベーシック・ロールプレイング』は、ゲームマスターがオリジナルのセッティングを作成したり、既存の作品を適応させたりする手助けとなるように設計されている。以下に、すべて同じフォーマットに基づいた一般的なセッティングの例と、それぞれの注釈を記載する。各項目には、推奨されるキャラクタータイプ（制限ではない）、そのセッティングで自然に受け入れられるパワー、装備の選択に役立つテクノロジー、冒険のタイプ、および適切なオプションルールが示されている。

### 先史時代

文明の黎明期以前、あるいはそれから隔離された原始的な部族環境。生活は短く過酷であり、通常、社会組織は家族や部族単位に限定される。先史時代の哺乳類が主な脅威となるが、歴史の分岐によっては恐竜が含まれることもある。

* **キャラクタータイプ:** クラフター、農夫、狩人、シャーマン、部族民。
* **パワー:** 原始的なシャーマンが魔法を使う場合がある。突然変異や超能力が存在することもある。
* **テクノロジー:** 先史時代には工業製品は存在せず、すべてが木、石、骨、革、毛皮、羽、粘土といった原始的な資源から形作られる。衣類、道具、武器、宗教的なトーテムや形見などがこれに該当する。熟練したクラフターはより良い石斧やタリスマンを作れるかもしれないが、それ以上の発展はない。大半のアイテムの質は劣悪または平均的であり、富という概念もない。
* **冒険:** 狩猟採集民のグループ間での優れた狩場を巡る部族間の対立、悪天候、凶暴な動物、あるいは大規模な狩猟が冒険の核心となる。歴史の分岐によっては、クトゥルフ神話の古代生物や、原始的な人類を奴隷にしようとする異星人、あるいは知性を持った恐竜や類人猿が支配種となり人類がその餌となるような進化の分かれ道が含まれることもある。
* **オプション:** なし。

### 青銅器時代

メソポタミアの時代から、聖書の古代、古典ギリシア、ローマの崩壊を経て、その後のヨーロッパの混沌とした分裂に至るまでの、シュメール、ギリシア、ローマ、エジプト、ペルシアなどの強大な帝国が栄えた時代。あるいは、想像上の古代世界を舞台にした「剣と魔法」のファンタジーセッティングともなり得る。

* **キャラクタータイプ:** ジャーナリスト、科学者、技術者以外なら何でも。
* **パワー:** 魔法や魔術。神に由来するものが一般的。超能力が存在したり、モンスターが突然変異を持つこともある。半神や伝説の英雄はスーパーパワーを持つ場合がある。
* **テクノロジー:** 青銅器時代の全盛期であり、鉄器時代の開花期でもある。金属加工が文化と商業を変革した時代。芸術が隆盛し、文明が誕生した。
* **冒険:** 殺伐としたファンタジー叙事詩や、文化と信仰を重視した神話的なテーマに適している。

### 鉄器時代

ローマ帝国の崩壊後、ヨーロッパの多くが混乱に陥った時代。社会的な進歩や生活の質の向上は見られるものの、しばしば残酷で啓蒙されていない時代として特徴付けられる。これにはノース人（バイキング）文化の興隆や、ローマが残した空白を埋めるためのヨーロッパ全域での地域紛争が含まれる。エルフやドワーフといった非人間種族、神話上の動物やモンスターを含むファンタジーセッティングにもなり得る。

* **キャラクタータイプ:** ジャーナリスト、科学者、技術者以外なら何でも。政治家はしばしば貴族であり、作家は通常、聖職者か詩人である。
* **パワー:** 魔法や魔術が最も一般的であり、神聖なもの、悪魔的なもの、あるいは異教的な性質を持つ。
* **テクノロジー:** 時として「暗黒時代」と呼ばれることもあるが、科学的発展や機械工学の改善、病気の治療法なども存在する。自然界の研究が盛んになり、貴族や聖職者の間で書物を作り知識を保存することが一般的となる。帆船の技術が洗練される。
* **冒険:** ローマ後のヨーロッパは事実上の終末後の荒野であり、庶民の生活は過酷であった。小規模な戦争や抑圧が日常的である。宗教間の対立が深刻で、混乱に満ちている。
* **オプション:** 忠誠、文化的修正、ダメージとヒット・ロケーション、教育/知識ロール、疲労ポイント、部位別ヒットポイント、読み書き、情熱、名声、正気度。

### ハイ・メディエフ（高世俗・中世）

封建時代。貴族、騎士道、王朝的な政府や社会構造がこの時代を特徴付ける。理想化されたロマンスが騎士道精神の世界を動かす一方で、残酷で冷酷な現実が対比として存在する。魔法は悪魔の業と信じられており、神聖なものは悪魔的なものと同じくらい現実的だと考えられている。また、文明の最後の残滓がネオ封建主義に陥った、遠い未来の終末後の世界を描写することもある。

* **キャラクタータイプ:** ジャーナリスト、科学者、技術者以外なら何でも。作家は通常、聖職者か詩人であり、科学者は自然界に興味を持つ聖職者である可能性が高い。
* **パワー:** 魔法や魔術が最も一般的であり、神聖、悪魔的、あるいは異教的な性質を持つ。
* **テクノロジー:** 商品の大量生産、初期のギルド構造、広範な貿易、商品の広範な流通が世界を変革した。一般的に、読み書き能力が普及していないため、書物や高度な知識へのアクセスは限られている。防具や武器はさらに効果的になり、後にバロック様式へと発展する。
* **冒険:** アーサー王やカールの伝説に類する冒険、騎士の探索行など。

### ハイ・ファンタジー

ハイ・メディエフのセッティングと似ているが、エルフやドワーフといった非人間種族が人間と共に存在し、しばしば人間と同盟を結んでオーク、トロール、ゴブリンなどと対立する点が異なる。神々は活動的であり、その崇拝者は神聖な能力を得る。治癒ポーション、魔法の剣、魔法の防具などが一般的。古代の遺跡が至る所にあり、地下にはダンジョンが広がっている。

* **キャラクタータイプ:** ハイ・メディエフと同様。
* **パワー:** すべて。魔法や魔術は神聖、悪魔的、あるいは異教的な性質を持つ。特定のモンスターには突然変異が見られ、超能力を使う種族も存在する。強力な超自然的存在は、神聖な能力や悪魔的な能力を装ってスーパーパワーを行使することがある。
* **テクノロジー:** ハイ・メディエフと同様だが、より非現実的。
* **冒険:** ダンジョン探索、魔法のアイテムを求めるクエスト、戦争、探索など。

### 帝国アジア

歴史上の日本や中国、あるいは武術のファンタジー世界を指す一般的な用語。ムガル帝国時代のインドもこのカテゴリーに含まれる。

* **キャラクタータイプ:** ジャーナリスト、科学者、技術者以外なら何でも。作家は詩人である可能性が高い。
* **パワー:** 魔法や魔術は一般的で、五行などの自然原理に基づいていることが多い。難解な武術の修練により、超能力やスーパーパワーのような能力を得ることもできる。
* **テクノロジー:** 中国や日本の芸術と科学は、同時代の西洋よりもはるかに発展しており、印刷機や火薬などが存在し、制度化された学問と官僚制度が栄えている。
* **冒険:** 一族や地域の支配権を巡る戦いから、マンガやアニメに見られるような時代錯誤な要素を取り入れたものまで幅広い。

### アラビアン・ナイト

古代アラビアやペルシアの世界。砂漠と大胆な冒険によって定義される世界。

* **キャラクタータイプ:** ジャーナリスト、科学者、技術者以外なら何でも。作家は通常、聖職者か詩人であり、科学者は自然界に興味を持つ聖職者である可能性が高い。

### 啓蒙時代とルネサンス

主にルネサンス期のヨーロッパを指すが、レオナルド・ダ・ヴィンチの発明が広く普及しているようなファンタジー的で奇想天外な現実を取り入れることもできる。芸術と科学が劇的に成長した時代であり、古代古典世界からの影響を強く受け、パトロンが芸術的発展を奨励した。

* **キャラクタータイプ:** ほぼすべて。
* **パワー:** 魔法や魔術が存在し得るが、宗教機関によって禁じられている場合がある。錬金術（魔法アイテムやエリクシールの作成）は学者にとって一般的な探求対象である。
* **テクノロジー:** ハイ・メディエフと同様だが、熟練した職人技、科学、発明の頂点にある。時計仕掛け、火薬、精密機械が開発され、蒸気、水力、風力の原理が探求されている。クロスボウの登場により、ボディアーマーは事実上不要となった。
* **冒険:** バロック的な政治情勢と、教会と啓蒙主義の間の深い対立が、ダイナミックなセッティングを生み出している。キャラクターは芸術のパトロンとして陰謀に巻き込まれることもあれば、その発見がトラブルを招く奇妙な発明家になることもできる。あるいは、大海原へ漕ぎ出したり、新世界への航海に乗り出すこともできる。
* **オプション:** 能力値の決定、文化的修正、教育/知識ロール、個人技能ポイントの増加、読み書き、情熱、名声。

### 大航海時代

ヨーロッパから南北アメリカ、アフリカ、インド、中国などへの外向的な拡大によって特徴付けられる時代。主に植民地化、改宗、領土併合、そして日和見主義が目的である。これは先住民にとって避けがたく悲惨な結末を招いた。先住民は犠牲となり、搾取され、あるいは奴隷化され、彼らの文化は排除され、犯罪視され、あるいは根絶やしにされた。イングランドではエリザベス1世の治世が黄金時代と見なされており、詩、文学、ファッション、演劇が溢れていた。しかし、大陸ヨーロッパは戦争によって引き裂かれている。スワッシュバックラー（剣戟冒険）がこの時代の定番である。

* **テクノロジー:** ルネサンス期に提供されたものの改善と洗練が特徴。戦場では火薬が一般的になり、初期の機械類がこの時代を定義する。この時期に土地を併合された先住民は、一般的に技術的に劣っており、圧倒的な火力によって打ち負かされた。

### 産業時代

この時代はヴィクトリア朝に対応しており、発明が溢れている。テクノロジーと製造技術の進歩によって定義され、前時代を現代への前駆体へと変貌させる。以下のテクノロジーセクションが、このセッティングの最も有益な説明である。

* **キャラクタータイプ:** ほぼすべて。
* **パワー:** スピリチュアリズムと近代化の間に亀裂が生じた時代。魔法や超能力が闘争の一側面を表す一方で、テクノロジーは実験的で奇妙な技術という形で多様なスーパーパワーを提供する。
* **テクノロジー:** 大量生産と工場スタイルの製造により、標準化された商品が人類史上かつてないほど広範に利用可能かつ安価になった。蒸気、石炭、ガス、その他のエネルギー源が家庭や都市で広く知られ、利用されている。都市はガス灯で照らされ、蒸気機関車がアメリカやヨーロッパを駆け巡り、石炭を燃料とする蒸気船が海を渡る。化学が精錬され、科学者は宇宙の多くの秘密を発見し始めている。間もなく自動車が登場し、人間の移動と都市を根本的に変えるだろう。歴史の分岐では、蒸気力とヴィクトリア朝の美学を混ぜ合わせた「スチームパンク」やレトロフューチャリズムに焦点を当てることが多い。
* **冒険:** 産業対スピリチュアリズムをテーマにした冒険。探検や新しい技術が、古い生活様式と劇的に接触する様子を描く。
* **オプション:** 能力値の決定、文化的修正、教育/知識ロール、個人技能ポイントの増加、情熱、名声。

* **冒険:** ガス灯の時代は、富裕なディレッタントと、人間が自らに与えうる最も不当で非人道的な条件を抱えた陰鬱な暗部が隣り合わせで存在するという巨大な二分法を提示している。

### ワイルド・ウェスト（西部開拓時代）

南北戦争中およびその後のアメリカで発生した時代。カウボーイ、ガンスリンガー、放牧地を巡る争い、ゴールドラッシュ、フロンティアの拡大。西部は新しい線路によって変貌しつつあり、東部人、ヨーロッパ人、中国人、解放された奴隷が、野生の新しい世界で自分の居場所を求めて押し寄せている。生存を賭けて戦うネイティブ・アメリカンの諸部族、そして飼い慣らせない広大な環境が危険である。

* **キャラクタータイプ:** ほぼすべて。

## パワーとセッティング

『第4章：パワー』では、パワーの5つの異なるシステムが、文脈（どのセッティングに適しているかなど）をあまり含まずに提示されている。上記の各セッティングの説明には、伝統的に関連付けられているパワーが含められている。伝統的な関連付けとは異なるセッティングでパワーを組み合わせることで、より斬新なセッティングを生み出せる。

*例えば、「暗黒時代」のセッティングに突然変異を追加し、キャラクターに奇妙な聖痕を宿らせるとしたらどうだろうか。それらは神聖な起源か、それとも悪魔的か？教会はこの奇妙な能力や変形を悪魔の血の結果だと考えるかもしれないが、キャラクターはそれらを天からの贈り物だと信じ、自分たちを恐れ憎む世界を守るために能力を使うかもしれない。*

## 適応

フィクション、映画、テレビ番組、コミック、他のゲームなどのメディアからセッティングを適応させることもできる。ライセンスゲームは数多く存在するが、最も明白な理由は、あなたやプレイヤーにとってそのセッティングが魅力的であるにもかかわらず、ルールセットが存在しない場合である。『ベーシック・ロールプレイング』を使用してセッティングを適応させる方法は多々あり、その作業量はほぼ完全にあなたの野心と費やせる時間次第である。以下は、他メディアからのセッティングをプレイ可能なゲームに適応させるための一つのアウトラインである。

### 忠実度

セッティングにどれだけ忠実に従うか？それを変更不可能なカノン（正史）として厳密に再現するか、それとも自分たちの目的のためのソースとして利用するか？創造的な拡張の余地が非常に大きいセッティングもあれば、より限定的なものもある。セッティングの雰囲気を正確に引き出すためにどれだけの努力を払うか、あるいは自分たちの好みやアイデアを優先させるかを選択する必要がある。どちらが優れているということはなく、ゲームマスターのスタイルやプレイヤーの期待によって異なる。

セッティングを完全にコピーすることは、オリジナル作品のファンにとって魅力的である。キャラクターが何かを成し遂げるための余地が十分に確保されていれば、その魅力は明らかだ。プレイヤーの馴染みやすさと「コミットメント」が大きく寄与する。この決定は、キャラクターの扱い（後述の「適応セッティングにおけるキャラクター」参照）に影響を与える。

セッティングを独自の創造性の踏み台として扱うことは、コミックの世界、シリアルテレビ、複数著者による書籍シリーズなど、異なるクリエイターからの新しいアイデアを許容するセッティングに最適である。過度の背景設定やカノンの罠を避け、プレイヤーに自由に世界を揺さぶらせることができるが、確立された設定から離れすぎると、そのセッティングを使用する魅力が薄れてしまう可能性がある。

適応セッティングで何を見たいか、プレイヤー自身に尋ね、どの程度の自由度を望んでいるかを知ること。

例えば、「ロビン・フッド」のキャンペーンでは、悪辣な当局に対して立ち向かうバンディット・ヒーローという全体的なテーマを維持し、ノッティンガムの人々の心をつかもうとする物語が良いだろう。プレイヤーはロビン・フッドの一味として、彼の命令に従いウィル・スカーレット、メイド・マリアン、タック修道士と共に戦いたいのか、あるいはロビン・フッドを自分たち全員が使う架空のアイデンティティにして、一味を丸ごと入れ替えたいのか。あるいは、リチャード王によってシャーウッドの森の守護者に任命され、人狼、妖精、古代の異教の神々といった超自然的な敵から領土を守る世界にするのもいい。

理想的には、ゲームマスターとプレイヤーが適応セッティングをプレイするための共通点を見つけ、全員が満足することである。全員がセッティングに投資し、それを探索することを熱望していることは、プレイにおいてすべてを変える。キャンペーン中にプレイヤーがどう感じているかを定期的にチェックすることを勧める（これはどのようなキャンペーンにおいても良い考えである）。

### 適応セッティングにおけるキャラクター

ソース素材をセッティングに適応させるのは、キャラクターがその世界にどう適合するかを最初に決定すると容易になる。ソース素材がキャラクター主導型である場合、プレイヤーキャラクターを彼らに似せたいのか、彼らに代わらせたいのか、あるいは彼らと交差させたいのか。これらはすべて異なる扱い方である。

* **「〜に触発された」**: セッティングを使いたい主な理由は、ソース素材のような冒険をプレイすることであるため、キャラクターをオリジナルに似せるのは通常、安全な賭けである。プレイヤーキャラクターはオリジナルであっても良いし、同じ鋳型に入れられたオリジナルではないキャラクターであっても、同様の役割を果たすものでも良い。
* **交換英雄**: プレイヤーは、より有名なキャラクター集団の影で生きる二級市民のようには感じたくないことがある。この場合、プレイヤーキャラクターにオリジナルの人物を置き換えさせる（同じ場所に収まる新しいキャラクターを作成するか、オリジナルのキャラクターをそのまま使用する）。
* **親友的ライバル**: もう一つの非常に魅力的な選択肢は、プレイヤーキャラクターをオリジナル主人公と同じ世界に存在させることである。彼らは面識があったり、親戚であったり、あるいは出会うこともある。このような場合、プレイヤーが「現実」の主要人物たちの脇役のように感じないように注意することが重要である。

### セッティングの記述

プレイヤーが世界で何をするかがわかったら、セッティングそのものに移行する時間である。まず、元のセッティングのトーンと大まかな詳細レベルを把握し、重要と思われる情報があればメモを取ること。ファンウィキやリソースを探すと楽になるだろう。すべての些細なキャラクターや詳細を記録する必要はほとんどないが、プレイヤーが重要だと思うものには注意を払うこと。

セッティング情報を整理するために使用できるセクションのリストは以下の通り：

* キャラクターオプション、職業、パワーなど。
* パワー（ある場合）。
* 文化または重要な生物。
* 伝統または文化的信念。
* 環境、興味深いポイント、聖地など。
* 乗り物と注目すべきテクノロジー。
* 宗教、社会組織、重要な教義。
* 社会、統治形態など。
* 注目すべき歴史的出来事。
* 国王や女王、大統領、宗教指導者、歴史的人物などの重要人物。
* グループ、組織、社会、教団など。
* 武器と防具（関連がある場合）。
* 注目すべき動植物。
* プレイヤーが独自のプロットを探すことが期待される場合の冒険の種。

また、これはセッティングの「高レベルのルール」を定義する時間でもある。どのパワーレベルがセッティングを最もよく表しているか？全体的な道徳的宇宙観はどのようなものか（例：「善は必然的に勝つ」、「人類は冷酷で慈悲のない宇宙における異常である」など）。

すべてのセッティングでこれらが必要というわけではなく、ゲームを実行し、プレイヤーの質問に答えるのに十分なだけを記録すればよい。事前にすべてを行う必要はない。答えを知らない質問に対しては「後で考えて伝える」とプレイヤーに言ったり、グループとして一緒に決めることもできる。

セッティングを開発する際にウィキや共有オンラインドキュメントを作成し、プレイヤーに公開することもできる。彼らが興味を持てば、セッティングの作成に協力してもらおう。

ただし、実際にプレイされるよりもセッティングの作成や適応に多くの時間を費やしているなら、何が必要で何が完全にオプションであるかを評価するために一歩下がってみることも大事だ。セッティングの要素を網羅的にカタログ化することに情熱を感じる人もいれば、一度読んで「これで十分だ。始めよう！」と決断する人もいる。自分がどちらの極端に近いかを見極めて行動すること。

このプロセスはオリジナルのセッティングでも同様だが、この場合は（プレイヤーも一緒に）詳細を作り上げることになる。

## 忠誠（オプション）

多くのセッティングには、より高次の力への信仰が含まれている。これには神、天使、聖人、悪魔、神聖な原理、あるいは抽象的な哲学的概念が含まれる。自分の信念に従って一貫して行動するキャラクターは、それに対する忠誠を持ち、忠誠度で測定される。神（あるいは複数の神々）が好むように振る舞うことで、献身を示す忠誠ポイントを得られる。忠誠はプレイ中に変化する可能性があり、新しい力が重要になるにつれて新しい忠誠が現れることもある。

キャラクターは一つ以上の存在や神から忠誠ポイントを得る可能性がある。人は日によって一貫して行動するとは限らず、最も道徳的で倫理的な人物であっても、信じられないような悪行を犯す可能性がある。忠誠システムにより、キャラクターは対立する力や複数の力に対して忠誠度を持つことができる。

一つの忠誠度が他のどの忠誠度よりも20ポイント以上高い場合、そのキャラクターはその力と**同盟**していると見なされ、その忠誠のおかげで特定の利益を得られることがある。ただし、スコアにかかわらず、キャラクターはこの忠誠を意識的に認めなければならない。忠誠は明白に思えるかもしれないが、認めなければ利益は得られない。

忠誠ポイントが失われることはほとんどない。常にプラスか0である。減少した場合でも0を下回ることはない。忠誠ポイントは行動への報酬であるため、複数の（あるいは少なくとも対立する）力を持つことが理想的である。一つの信念体系では罰せられる行動が、別の体系では報われることが多いため、キャラクターは好みの神聖な力に反して行動してもポイントを失うのではなく、支持する力と対立する力によってポイントを与えられる。

同盟キャラクターがより高いレベルの忠誠を獲得すると、タイトル、パワー、責任などで表される、関連する教団や教会内での地位を得る可能性がある。

### 開始時の忠誠

忠誠ルールを使用する場合、利用可能な忠誠の数と同じ回数だけ 1D6-2（最低0）をロールし、ゲーム開始前に獲得した忠誠ポイントを表す。ゲームマスターは以下のいずれかをプレイヤーに行わせることができる：

* ロールされた順に忠誠合計を割り当てる。
* 自由に忠誠スコアを割り当てる。

精神的な力に結びついたパワータイプがあれば、適切な忠誠にそれぞれ+1ポイントを追加する。同様に、突然変異があれば適切な忠誠に+1ポイントを追加する。オカルト主義者、聖職者、シャーマンの職業のキャラクターは、1/2 POW（端数切り上げ）に等しい忠誠ポイントを希望通りに分配する。

### 忠誠の向上

忠誠を好む行動は、キャラクターの忠誠スコアを増加させる。忠誠ポイントを与える可能性のある行動リストについては「忠誠の作成」を参照のこと。冒険の後、キャラクターが力に好まれる方法で振る舞ったなら、プレイヤーに忠誠テストを行わせる。これは「技能の向上」の経験チェックと同一である。成功すれば、忠誠スコアは+1D6ポイント増加する。

キャラクターが複数の忠誠によって奨励される行動を行った場合、適用されるすべての忠誠に対して経験チェックを要求し、成功すればそれぞれ+1D6ポイントを得る。

### 複数の忠誠

**忠誠の指針にかかわらず、すべてのキャラクターには自由意志があり、望むように行動できる。** キャラクターは、利用可能な忠誠のすべて、一部、またはなしのスコアを持つことができる。ただし、そのスコアが次に高いスコアよりも20ポイント以上高く、かつキャラクターがその忠誠を認めている場合にのみ、最高スコアの力と同盟関係にあると見なされる。

### 忠誠の維持

同盟キャラクターが忠誠の利益に反する行動をとった場合、その忠誠を試すためにD100ロールを要求できる。ロールがキャラクターの現在の忠誠スコアを上回った場合、逸脱した行動の度合いに応じて1D4から1D8の量だけ、反対の忠誠スコアを増加させる。ロールが現在の忠誠スコア以下であれば、結果は生じない。

キャラクターの忠誠スコアが100以上で、その大義にコミットしている場合、その忠誠に反する行動はキャラクターの危険にさらされることをプレイヤーに警告する。強い忠誠を持つキャラクターは、忠誠の恩恵を失い、仲間の信者にとっての敵と見なされる可能性がある。神聖またはカルマ的な罰が科されるか、利益を回復するために贖罪をしなければならない場合がある。贖罪には、断食や長時間の瞑想、クエスト、痛悔の行為、何らかの犠牲、浄化の儀式などが含まれる。

### 忠誠の作成

忠誠を定義し、それぞれが何を代表するかを確立する必要がある。プレイヤーキャラクターの忠誠を巡って少なくとも二つの勢力が競い合うようにすると、ある信念と別の信念の間の闘争が強調される。

次のステップは、様々な行動に対してどれだけの忠誠ポイントが与えられるかを決定すること。これを行う最も簡単な方法は、ゲーム内で発生しそうな行動のチェックリストを作成し、どの力がどの行動に忠誠ポイントを与えるかを決めることである。以下は適した行動の例である：

* 自分より弱い者を助ける
* 不名誉な行動をとる
* 名誉ある行動をとる
* 弱者や困窮者への慈善
* 同盟勢力を称えるものを作る
* 超自然的な存在を破壊する
* 他の勢力にとって神聖なものを破壊する
* 投獄されている者を解放する
* 同盟勢力を不敬に呼び出す
* 同盟勢力を敬意を持って呼び出す
* 冷酷に殺害する（殺人）
* 正当防衛で誰かを殺す
* 忠誠への大きな貢献
* 忠誠への小さな貢献
* 誰かを保護する
* 誰かの命を救う
* 窃盗

各行動について、反対の行動に対する忠誠報酬をリストアップすることを勧める。例えば「自分より弱い者を助ける」は「自分より弱い者を搾取する」によって対立する可能性がある。主要な行動には3ポイント、重要なものには2ポイント、軽微なものには1ポイントの価値がある。

この後、忠誠が何らかの利益を提供するのか、それとも忠誠ポイントがその力への献身の尺度に過ぎないのかを決定する必要がある。これらは「忠誠の恩恵」（後述）から引き出すか、神聖な力の性質により具体的なものにしてもよい。

特定の忠誠で100以上に達したキャラクターは、その忠誠の**アポセオシス（神格化）**、すなわちその神聖な力の意志の化身と見なされる場合がある。

キリスト教神学を取り入れたキャンペーンでは、「天国」と「地獄」が二つの対立する忠誠となり、最高の忠誠はキャラクターの死後の行き先を強く示す指標となる。神々のパンテオンがあるキャンペーン設定では、キャラクターは複数の神々に忠誠を持つことができる。

忠誠は必ずしもファンタジー世界の神々や宗教に結びついている必要はない。SF設定では、忠誠はすべての生物を結びつける神秘的な力のような抽象的なものであり、明るい側と影の側が対立する可能性がある。スーパーヒーロー・セッティングの忠誠は「法」と「無秩序」、あるいは「正」と「邪」に向けられる可能性がある。スーパーヒーローは悪者を倒し罪なき者を救うことで忠誠を得、スーパーヴィランは犯罪を行い正義から逃れることで報われる。

### 忠誠の恩恵

忠誠に何らかの利益があるかどうか、そしてそれが何であるかを決定する。一つの忠誠が利益を与えるなら、他のものも以下のような同等の恩恵を提供すべきである：

* キャラクターのパワーポイントを消費した後、忠誠ロールに成功すれば、即座に現在の忠誠スコアの最大1/10（10%）（端数切り上げ）を、パワーポイントの追加備蓄として獲得できる。忠誠ポイントはこの恩恵で変化しない。これらのポイントはキャラクターの最後のパワーポイントが消費される際に引き出さなければならず、そうでなければ気絶する。これらのポイントは通常のパワーポイントと同一である。これはゲームセッション中に3回まで試行できる。この能力を使用した場合、冒険の終了時に忠誠テストを行える。
* 忠誠ロールに成功すると、キャラクターは1セッションにつき1回、現在の忠誠スコアの1/5（20%）（端数切り上げ）までを一時的なヒットポイントとして使用できる。忠誠ポイントは変化しない。これらのヒットポイントは、キャラクターの通常のヒットポイントより先に消費され、失われた場合、いかなる方法でも回復しない。セッション終了時に、キャラクターの通常のヒットポイント合計を超えるヒットポイントは消滅する。これらの追加ヒットポイントを使用した場合、冒険の終了時に忠誠テストを行える。
* 忠誠ロールに成功すると、特定のロールの既存技能値に追加できる、追加技能ポイントの備蓄として、忠誠スコア全額に等しいポイントを作成できる。これはセッションにつき3回まで行える。忠誠ポイントは変化しない。プレイヤーはどの技能にこれらのポイントを追加し、いくつ追加するかを選択できる。技能ポイントの増加は、ロール前に宣言しなければならず、調整された数値は、特殊な成功を判断する際に利用される。これらのポイントは技能チェックにのみ使用でき、抵抗ロール、能力値ロール、忠誠ロール、経験ロールなどには使用できない。これらのポイントを使用した成功した技能ロールは、経験チェックの対象にはならない。これらの追加技能ポイントを使用した後に、冒険の終了時に忠誠テストを行える。
* 力と同盟している（二番目に高い忠誠よりも20以上高い）キャラクターは、神の介入を呼び求めることができる。成功のチャンスはクリティカル成功と同じである。クリティカル成功が出れば、直接的、あるいは代理人や代理物を通して、あるいは自然界の明らかに奇跡的な現れを通して、その力が介入する。一般的に、ほとんどの神は事実上無制限の力を持っているため、この援助は並外れたものとなる可能性がある。キャラクターは冒険の終了時に忠誠テストを行える。

同様の恩恵を作成して、疲労ポイント、正気度ポイント、あるいはアイデアロールの形での神の啓示を許可することもできる。

### 神格化（アポセオシス）

前述のように、キャラクターが忠誠スコアで100以上に達し、その忠誠と同盟関係にある場合、ビジョン（あるいはその他の神のメッセージ）を通じて、それに奉仕し、そのアポセオシスになるよう求められることがある。他の忠誠のスコアは関係ない。アポセオシスは自動的ではない。キャラクターはその信仰と行動を通じて、これが正当であることを証明しなければならない。申し出が受け入れられた場合、アポセオシスが発生し、キャラクターは生けるアバターとなり、その力の断固たるチャンピオンへと変わる。

忠誠の恩恵は加算され続ける。キャラクターは自由意志を維持し、仕える力を裏切ることもできる。キャラクターがアポセオシスを拒否した場合、忠誠ポイントは死または引退まで通常通り増加し続ける。

アポセオシスを受け入れると、キャラクターに一つ以上の重要な恩恵が授与される可能性がある。適した報酬や恩恵を作成することをお勧めする。以下はアポセオシスが授与するものの例である：

* 真実の愛に出会う、あるいは完全な幸福と世界の混乱からの逃避を達成できる精神的な安息の地を見つけるといった、記念碑的な個人的目標の達成。これは悲劇的な結末、すなわちキャラクターが唯一ふさわしい結果が死であるような壮大な宿命を遂げることにもなり得る。
* 肉体が通常通り老化したり、病気や他の苦しみを受けたりしない限定的な不老不死。キャラクターの回復率は変わらず、武器や他の傷害によって殺される可能性がある。歪んだ神は、この不死の体を醜い傷跡、終わりのない痛み、あるいは取り除くことのできない超自然的な刻印など、混ぜ合わされた祝福にすることを選ぶかもしれない。
* 永久的なヒットポイントのCON+SIZへの増加（あるいは単に現在のヒットポイントを倍にする）。部位別ヒットポイントを使用している場合は、それに応じて調整する。合計ヒットポイントを使用している場合は、倍にする。
* プレイヤーが選択した、忠誠の性質に適した3つの技能の技能値を倍にする。
* クエストの結果、あるいはそれを獲得する他の手段を通じて、神の手段によって武器、アイテム、あるいは重要なアーティファクトが提供される。このアイテムは非常に強力で、キャラクターの忠誠を共有または対立する者には一目でわかる。
* 神聖な力によって完全に消費され、生けるアバターとして再生する。必要に応じて能力値を失うか獲得し、最大パワーポイントを倍にする（ただしPOW能力値自体は変化しない）。キャラクターは天使や悪魔に似た神的存在になることさえある。

この時点で、プレイヤーキャラクターはPOW×3の確率で、その力と直接的かつ即時的なコミュニケーションを開始できる。その力はキャラクターの人生を支配し、頻繁かつ直接的にコミュニケーションをとる。これは、その意志を促進しない行動に介入するという妨げになる可能性さえある。

## 情熱（オプション）

冒険はしばしば強烈な感情に満ちており、それが英雄的行為の頂点や悲劇の深淵へと繋がることがある。これらは**情熱**と定義され、様々な存在、グループ、場所、あるいは自分自身に対する明確な感情的なつながりである。愛、憎しみ、恐怖、献身、忠誠は、互いに恐ろしい対立を引き起こすだけでなく、個人的な名誉の規範を試すものでもある。これらは技能のように評価され、D100でロールされ、キャラクターは**奮起（inspired）**し、信念によって行動をチャージされる。奮起したキャラクターは、超人的な努力と成功の可能性によって課題を乗り越えやすくなる。このようなロールに失敗すると、**絶望（despair）**や抑鬱に陥る可能性がある。

技能と同様に、情熱は経験による成功した使用を通じて向上し、情熱に反する行動によって低下するものもある。プレイヤーは常にキャラクターの行動を制御している：情熱は、キャラクターがいかに異なる行動をとったとしても、対象についてどう感じているかを知らせるだけである。

### 基本的な情熱

最も一般的な情熱をここに説明するが、このリストは網羅的ではない。技能の専門と同様に、情熱の後の括弧内は、適切な焦点を決定しなければならないことを示す。

#### 献身（神格）

神や神聖な力への献身は、神や神聖な力、存在への人生の個人的な捧げ物を表す。これは誠実な感情的な献身と強い信仰を示す。奮起のために使用されるとき、その信仰はキャラクターの中で現れ、小さな勇気を吹き込む。

#### 恐怖（種族または個人）

恐怖は、おそらく最も強力な情熱の一つであり、良くも悪くもあらゆる種類の行動を駆り立てる。恐怖は、対象から逃げ出したり、その存在から逃れるために不合理に行動したり、あるいは逆反応を引き起こしたりする可能性がある。

一般的な恐怖は、特定のグループや個人（以前の敵や裏切った親戚など）に焦点を当てることができる。「老齢」や「地震」のような一般的な概念や力に向けられた恐怖は定義できず、死のように合理的な存在なら誰でも恐れる対象に対しては通常役に立たない。

キャラクターを奮起させるには、恐怖の対象がその場にいるか、その存在が差し迫っていなければならない。対象が数百キロ離れていて到着の兆候がない場合、恐怖によって動機付けられることはない。対象に直面する脅威は現実的かつ即時でなければならない。

恐怖によって奮起した結果生じる行動は、回避、逃走、防御を助けたり、追い詰められたときに暴力的な抵抗を促すこともある。しかし、キャラクターが恐怖の源に接触するような行動をとろうとする場合、ゲームマスターは恐怖の情熱のロールを要求することもある。

#### 憎しみ（グループまたは個人）

憎しみは、人種差別、偏見、あるいは実在または想像上の過去の過ちに対する特定の憎悪を通じて、残念ながら多くの人々を動機付ける。

奮起に使用される場合、憎しみは特定の対象または対象のタイプに対してのみ使用でき、憎しみの対象と同盟している者には適用されない。憎しみはまた、特定の理由で特定の人々を標的にすることもできる。

#### 名誉

名誉は武士の徳であり、尊厳、誠実、誇りの個人的な規範である。個人的名誉は解釈の余地がある曖昧な問題ではない。名誉ある行動と不名誉な行動の違いは、どんなに振る舞おうとも誰の目にも明らかである。不名誉テーブルは、ほとんどの人が平均的な人間にとって不名誉な行動であると同意するものをリストアップしている。これらの行為を行うことは、名誉を減少させる。

| :---- | :---- |

| 臆病 | -5% |
| 戦場からの脱走 | -5% |

名誉はキャラクター固有のものであり、他の社会的義務は含まれない。誰かが家族を侮辱しても名誉は損なわれない――「愛（家族）」がそれをカバーする。同様に、誰かが自分の神を侮辱しても、名誉ではなく「献身（神）」や「忠誠（寺院）」の情熱を参照すべきである。

名誉にはキャラクターが選んだほぼすべてのものが含まれる可能性があり、この情熱を持つ際は独自の個人的な名誉の規範を開発すべきである。非常に高い名誉を持つ者は侮辱と解釈されるあらゆる言葉に怒るかもしれないが、低い、あるいは名誉を持たないキャラクターは自分について何を言われても気にしないかもしれない。

#### 愛

愛は、ある個人が別の個人やグループに対して感じる感情的な絆や魅力である。キャラクターは多くの愛を持つことができる。

* **愛（家族）**は、どの時代や文化の人類にとっても共通の自然な感情である。親しい家族は、しばしば所属する最初で最も重要なコミュニティである。家族はお互いに支え、守り、復讐することが期待されている。
* **愛（個人）**は、他の人に対する深い感情と魅力を示す。通常は物理的および肉体的なコミットメントを意味するが、報われない愛も含まれる可能性がある。

#### 忠誠（グループまたは場所）

忠誠は、家族を超えた社会全体の礎である。コミュニティのメンバーがお互いに感じる社会的絆である。それにより、サポートのためにそのコミュニティを呼び出すことができる。

相反する忠誠を持つキャラクターは、それぞれの忠誠度を使用して適切な行動を決定できる。プレイヤーはより高い忠誠度に基づいて選択するか、対立ロールとしてテストできる。このように、プレイヤーは対立ロールを使用して、キャラクターが衝突した場合に故郷への忠誠に従うか個人への忠誠に従うかを判断できる。

* **忠誠（コミュニティ）**は、キャラクターが自分の文化と持つ絆の尺度である。通常、そのコミュニティやメンバーに対する侮辱や傷害に復讐する義務が含まれる。忠誠（コミュニティ）は、問題のコミュニティの支援を得るために使用される。
* **忠誠（場所）**は、住んでいる場所、戦う場所、あるいは愛着を持つ場所のために死ぬ意思の尺度である。これは故郷、都市、あるいは国であってもよい。
* **忠誠（個人）**は、支配者、上司、あるいは別のパトロンなど、特定の個人に対するキャラクターの絆の尺度である。戦士は指導者に対して個人的な忠誠を負う。指導者は見返りに、報酬、サポート、その他の特権で信者に報いる。忠誠（個人）は、その個人の個人的な支援を得るためにも使用される。

その他、「不信感（個人またはグループ）」、「尊敬（個人またはグループ）」、あるいは名誉のように機能し強欲な行動を促す「貪欲」のような情熱が存在する可能性がある。プレイヤーと協力して他の情熱を考案できるが、性格特性が使用されている場合は、それらとあまり重複しないように注意すること。

### 開始時の情熱

開始時の情熱を決定する最も簡単な方法は、プレイヤーに定義させることである。キャラクター作成時、各プレイヤーに3つの情熱を選択させる（1つは80%、2つは60%）。

必要に応じて、キャラクターの文化や出身地に基づいて情熱を割り当てたり変更したりできる。

### 情熱の使用

情熱はキャラクターの人生の意図を定義し、奮起させるために機能する。ゲームマスターは情熱ロールを要求できる。また、プレイヤーがゲームマスターの承認を得て提案することもある。情熱がプレイに影響を与える方法は以下の通り。

#### ロールプレイングの指針

情熱は、キャラクターが対象に対して感じる感情の度合いの数値的評価であり、キャラクターがどう行動するか疑問がある場合にプレイヤーが使用できる。情熱が高いほど、キャラクターはそれに基づいて行動する可能性が高くなる。情熱が低いほど、キャラクターはそれを無視できる。

プレイヤーは常にキャラクターを制御しているが、明らかな行動方針が不明確な場合や、ゲームマスターがキャラクターが劇的に「キャラクターらしくない」行動をとっていると判断した場合に、情熱ロールを使用できる。プレイヤーが主導権を握っている間も、ゲームマスターは（ロールされた、または高いスコアの）情熱に反する行動を「あなたのキャラクターはこれに悪い予感を感じているが、押し進んでいる」といったコメントで描写できる。

#### 実証とサポート

忠誠を持つキャラクターは、同じ忠誠を共有していることを誰かに納得させるために、それをロールするように求められるかもしれない。自分の「献身」「憎しみ」「愛」「忠誠」を実証して他者を動かし、良い手本となることは、情熱をプレイで使用する素晴らしい方法である。成功すれば相互サポートと援助が提供され、失敗すれば偽善者として拒絶される可能性がある。

#### 奮起（Inspiration）

キャラクターは情熱によって奮起しようと試み、ゲームマスターの承認を得て技能を強化するためのロールを要求できる。奮起の試みは、状況や「シーン」（戦闘の期間、社交的な集まり、アクションシーケンスなど）につき一度しか行えない。同じ行動を試みるたびに奮起ロールを行うことはできない。奮起は、戦闘やバトルなど、活動を完了するためにかかる時間続く（最大期間は1日）。疑問がある場合、ゲームマスターが奮起の期間を決定する。情熱に基づく奮起の試みに時間はかからない――それは他の行動の一部として行える。

情熱ロールを試行できるかどうかの最終決定権はゲームマスターにある。情熱ロールは報われるだけでなく、非常にリスクが高いこともあることをプレイヤーに警告する：情熱ロールのファンブルは絶望をもたらす！キャラクターがその状況で既に情熱によって奮起するためにロールしていたら、別の情熱であっても再試行することはできない。さらに、奮起によるボーナスは、他の技能からの強化と組み合わせることはできない。

奮起を試みる適切さとその期間についてはゲームマスターが最終決定権を持つことを忘れずに。プレイヤーはD100で情熱のレーティングに対してロールしなければならない：

* **クリティカル成功:** 選択した技能が、タスクまたは状況の間、一時的に+50%のボーナスを受ける。情熱において経験チェックを得る。
* **スペシャル成功:** 選択した技能が、タスクまたは状況の間、一時的に+30%のボーナスを受ける。情熱において経験チェックを得る。
* **成功:** 選択した技能が、タスクまたは状況の間、一時的に+20%のボーナスを受ける。情熱において経験チェックを得る。
* **失敗:** キャラクターは意気消沈し、その状況またはシーンで行われるこれ以降のすべてのロールを-10%修正する。このペナルティは次のシーンで終了する。
* **ファンブル:** 情熱が即座に-1D10%修正され、キャラクターは絶望に打ちのめされる（以下の「絶望」テーブルを参照）。絶望の期間中、キャラクターは逃げたり隠れたりすること以上の行動は事実上不可能となる。ただし、適切な状況下では、ゲームマスターがある程度の行動を許可することもある。

##### 絶望

| 結果 | 絶望の期間 |
| :---- | :---- |
| 1–3 | 1D10ラウンド |
| 4–7 | 1D10+10ラウンド |
| 8–9 | 日没、日の出、または同等の時間 |
| 10 | 1D3日 |

情熱が0%になった場合、キャラクターシートから削除する。情熱は0を下回ることはない。さらに、キャラクターは失われた情熱を二度と回復することはできない：それは枯渇し、ゲームマスターが並外れた状況や行動がその復帰に値すると判断しない限り、更新できない。

### 強制ロール

80%以上の情熱は固く保持された信念とつながりを表しており、軽々しく扱ったり、都合の良い時だけ使用したりするものではない。そのような極端な情熱は、ゲームマスターが選択した場合、これらの信念のためにプレイヤーに強制ロールを要求することがある。一般的に、例えば「憎しみ（ナチス）95%」を持つキャラクターが戦闘後にナチスを見逃すような、関連する情熱の評価に不適切な行動をプレイヤーがとった場合、ゲームマスターはいくつかの選択肢を持つ。

* 情熱を80%未満に減らす。
* 対立ロールとして、別の情熱でその情熱に対抗する。対立能力がルーンや情熱のコンテストに勝った場合、プレイヤーは主要な情熱を変更することなく異なる方法で行動できる。この場合、競合する情熱が勝ったことになる。

### 情熱の獲得

情熱はプレイ中に簡単に獲得できる。キャラクターは敵、愛する人、同盟者、忠誠を得る機会が数多くあるべきである。情熱の導入については、プレイヤーとゲームマスターの両方が合意すべきである。キャラクターにとって重要なことが発生したとき、ゲームマスターまたはプレイヤーが情熱が生成されたことを示唆できる。一般的に開始値は60%だが、状況によってはそれ以上になることもある。

### 情熱の自発的な減少

情熱が80%以上のキャラクターが、その情熱に直接反する行動をとる場合、単に情熱を80%（またはそれ以下）に下げるか、別の情熱でその情熱に対抗しようとすることができる。ただし、キャラクターは以下の方法で情熱を減らすことを望むかもしれない：

* 経験が決定されるとき、下げる情熱を選ぶ。経験チェックがある場合、その時点で下げることはできない。テストされておらず、プレイヤーが減らすことを望む場合、経験チェックと同じようにロールする。経験ロールが失敗した場合、情熱を-1D6減らす。
* 50%以下の情熱は、対象に対する両価性を表しているため、プレイにおいて大きく無視できる。必要に応じてキャラクターシートから削除できる。

## 名声（オプション）

名声は、キャラクターの名声、悪名、評判を測定する。これには家族の背景（関連がある場合）と、名声を得るために行った行動が含まれる。キャラクターの名声が高まるにつれて、人々は彼らをますます意識し、彼らについてより多くのことを知るようになる。

### 名声の獲得

名声は他者の注目を集めるようなことを行うことで得られる。ニュースに出る、公職に選ばれる、何か大きくて注目に値することを成し遂げる、有名人になる、有名な人を助ける、有名なアイテムを所有する――これらはすべて、キャラクターの名声を高める行動の例である。

名声は経験チェックでは向上しない。その代わりに、プレイ中に発生する達成や出来事に基づいてゲームマスターの判断で向上する。名声は否定的な行いによっても高まる可能性がある。名誉が低下するのと異なり、不名誉な振る舞い、悪行、壮大な失敗は、叙事詩的な達成と同じくらい（あるいはそれ以上に）有名にすることができる。

以下の「名声獲得」テーブルは、名声がどのように向上するかを示している。名声は秘密裏や曖昧な状況で行われた行動からは得られないことに注意すること。ゲームマスターは、記載されている例を使用するか、他の増加のための指針として使用することを推奨する。

一回の行為からの名声は一度しか得られないが、ゲームマスターは同じ行動の複数回の発生に対して修正できる。情熱を使用している場合、ある行為で名声を得ると同時に名誉を失うこともあり得る。

**獲得**: +2D6以上

**例**

* ほとんど不可能な努力での伝説的な成功を収める。
* 軍隊を率いて勝利する、あるいは単独で軍を倒す。
* 神的または不滅の性質を持つ敵を倒す。
* 王や女王と結婚する、あるいはそうなる。
* 神の予言の焦点となる。
* 人気のある本やドキュメンタリーに取り上げられる。
* 新しい主要な寺院や宮殿のような壮大な建造物を建てる。
* 劇的な敗北。
* 両親や子供を殺す。
* 最も暗い裏切りや悪名高い行為。

### 名声の追跡

プレイヤーは、キャラクターの名声の源と、どれだけ獲得したかを追跡すること。名声が向上した後は、減少することはない。単に異なる理由で有名になるだけである。ただし、ゲームマスターは成功のチャンスを修正できる（「名声修正」を参照）。

### 名声の使用

名声は二つの方法で使用される：誰かを特定するため、あるいは他者を印象付けるため（事実上「私が誰かを知っているか？」と言うこと）。

#### 誰かを特定する

名声は、ノンプレイヤーキャラクターがキャラクターを特定し、彼らが有名な理由を知るためにゲームマスターによって使用される。あるいは、プレイヤーが特定のノンプレイヤーキャラクターについて聞いたことがあるかどうかを判断するためにロールできる。

適切な名声ボーナスまたはペナルティ（「名声修正」を参照）を適用してロールする。これは通常の技能や能力値とは異なり、ロールは自身の名声ではなく、対象の名声に対して行われる。キャラクターは、ある種のコミュニケーション技能で名声（あるいは他の誰かの名声）を補強し、相手を褒めちぎることもできる。適切であれば、その分野で注目されている対象であれば、知識や教養技能を使用して名声を補強できる。

ロールが成功すれば、名声に対してロールされた人物が認識される。これはそのノンプレイヤーキャラクターがキャラクターにどのように反応するかに影響する。質の良い成功は、より多くの情報を与える。失敗は知られていないことを意味し、ファンブルは悲惨な誤解や人違いを意味する。

誰でも自分の正体を否定できるが、現代的な設定ではますます難しくなる。

#### 他者を印象付ける

名声は、適切であれば、いくつかのコミュニケーション技能を補強するために使用できる。同様に、ゲームマスターはキャラクターがノンプレイヤーキャラクターの反応を揺さぶることを許可できる。

名声を使用して別の技能を補強するには、キャラクターの名声に対してロールする：

* **クリティカル成功:** キャラクターの名声が、使用するコミュニケーション技能に+50%のボーナスを与える。
* **スペシャル成功:** キャラクターの名声が、使用するコミュニケーション技能に+30%のボーナスを与える。
* **成功:** キャラクターの名声が、使用するコミュニケーション技能に+20%のボーナスを与える。
* **失敗:** キャラクターは使用するコミュニケーション技能から-20%を減算する。
* **ファンブル:** キャラクターは使用するコミュニケーション技能から-50%を減算する。

### 名声修正

名声は聴衆の社会的距離によって修正される。通常、家族、職場、近隣地域での名声は向上する。一方で、見知らぬ人や外部の人に対しては名声は低下する。有名な政治家、英雄、有名人であっても、遠い場所では完全に無名かもしれない。同様に、時間が経つにつれて名声の関連性は薄れる。観測者の社会的近接度に基づいて、キャラクターの名声に修正を加える。

##### 名声修正

| 観測者は… | 修正 |
| :---- | :---- |
| …同じ家族、会社、地域出身、または共通の知人がいる。 | +25% |
| …旅行好きで、ゴシップ/ニュースを追いかけ、人脈が広い。 | +10–25% |
| …同じ文化や地域出身。 | — |
| …キャラクターの社会的ネットワークや文化グループの外側、または最近のニュースに疎い。 | -25% |
| …名声を得た場所の外側だが、地理的に同じ地域内、または別の世代。 | -50% |
| …名声を得た地理的な地域の外側、またはキャラクターから数年経っている。 | -75% |

## 正気度（オプション）

キャラクターが暴力や事故によって物理的に損傷を受ける方法はたくさんあるが、一部のゲームでは、最も強力な脅威は人間の精神の安定に対するものである。「第2章：キャラクター」で定義されているように、キャラクターには「正気度（SAN）」と呼ばれるオプションの能力値がある。正気度ポイントが多いほど、心理的に安定している。正気度ポイントはトラウマ――恐ろしい超自然的なモンスターとの遭遇、死や暴力的な出来事の目撃、拷問のような意図的な物理的危害――を通じて失われる。正気度を試される出来事に直面すると、キャラクターは現在の正気度ポイント合計に対してロールする。失敗はSANポイントの減少を意味し、成功は失うSANが少ないことを意味する。正気度ポイントは、カウンセリング、SAN損失の原因を打ち負かす、または個人的な向上によって回復できる。

なお、このシステムはプレイ目的のための抽象化であり、精神疾患の現実を近似したり、それを何らかの形で軽視したりする意図はない。

### 正気度のメカニズム

各キャラクターにはSANという能力値がある。初期SANはPOW×5である。キャラクターのSANは、後でPOWが変化しても変わらない。キャラクターの開始SANの半分が「一時的狂気スコア（TIS）」となる。SANはゲームプレイを通じて劇的に変化するが、TISは決して変化しない。ゲームマスターの判断で、普通の人間を扱うゲームではTISをPOWと等しくし、一時的狂気の可能性を大幅に高くすることもある。

時折、キャラクターはD100でSANロールに成功しなければならず、失敗するとSANを失う。成功するチャンスは現在のSAN以下である。ロールが失敗した場合にどれだけのSANが失われるかはゲームマスターが決定する。特に恐ろしい経験では、ロールが成功してもSANを失う場合があるが、これは合計SAN損失の数分の一になるだろう。

各キャラクターシートには現在のSANとTISを記録する領域がある。開始SANとTISは恒久的にマークすること。現在のSANは、ヒットポイントやパワーポイントのように、変化するたびに（紙のシートであれば）鉛筆で書くこと。

5分間（1ターンに等しい）の間に失われたSANがTIS以上になった場合、キャラクターは一時的に狂気に陥る。キャラクターに対して「一時的狂気」テーブルで1D6をロールし、「一時的狂気期間」テーブルで1D8をロールする。前者はキャラクターがどのような影響を受けるかを示し、後者はその期間を示す。

一時的な狂気に苦しんでいるときは、プレイヤーにキャラクターの状態を伝え、適切であればロールプレイを求めること。

時間、カウンセリング、強力な薬物、いくつかのパワー、あるいは神の介入が一時的な狂気を癒すかもしれない。適切な薬物は、利用可能であれば、技能で作るか購入できる。一時的な狂気への対処方法は、ゲームマスターの判断で他にも存在する可能性がある。

##### 一時的狂気

| 結果 | 説明と効果 |
| :---- | :---- |
| 1 | **緊張病**；キャラクターは胎児のような姿勢をとる。 |
| 2 | **昏迷**；キャラクターは絶え間なくうわ言を言うか、何も見ずに空間を凝視する。 |
| 3 | **パラノイア**；キャラクターは明晰だが、ほとんどすべてに対して不合理な疑念を抱いている。 |
| 4 | **恐怖症**；キャラクターは狂気の源に関連する何かに大きな恐怖を抱く。 |
| 5 | **健忘症**；キャラクターは自分が誰であるか、あるいはSAN損失の前後になにが起こったかを思い出せない。 |
| 6 | **自殺的絶望**\* **または死への願望**；キャラクターは、自身の死が精神的苦痛から逃れる唯一の手段だと確信している。 |

\* キャラクターは自殺行為を強要されることはなく、ゲームマスターはこの結果を使用する際には細心の注意を払い、関係するプレイヤーの感受性に配慮すること。

キャラクターのSANが0に達すると、恒久的に狂気に陥ったと見なされ、プレイから引退するか、ゲームマスターが制御するノンプレイヤーキャラクターとなる。恒久的な狂気の唯一の治療法は、神の介入、あるいは（広範な心理的再プログラミング、長年のセラピーと瞑想など）ゲームマスターが決定するその他の主要なプロセスである。その場合、回復するSANの量はそれに応じて決定される。

### 最大正気度

知識技能の「冒涜的知識」専門のような特定の技能は、最大SANを減らす可能性がある。この技能が向上するにつれて、100から差し引く。その結果が、元の初期SANよりも低い場合でも、キャラクターが持つことができる最大SANとなる。

***例：*** *SAN 75（POW 15×5）で知識（冒涜的知識）43%を持つキャラクターの新しい最大正気度は 57%（100-43=57）となる。*

### 正気度ポイントの回復

キャラクターは失ったSANを回復できるが、初期の最大SAN合計を超えることはない。SANを回復する方法は以下の通り：

* **成功:** SAN損失の原因を打ち負かすことは、その原因が脅かした潜在的なSAN損失の半分に相当する価値がある可能性がある。ゲームマスターは「打ち負かす」条件を解釈し、回復する正確な量を決定する。これはロールすることもできるし、損失した者だけでなく、打ち負かすことに参加した全員に一律の量として与えることもできる。
* **カウンセリング:** 心理療法技能を参照。一般的に、成功した技能ロールは1D3-1 SANを回復する。
* **薬物:** いくつかの薬物や物質は、ゲームマスターの判断で失われたSANを回復できる。
* **パワー:** いくつかの超能力と「転送（Transfer）」スーパーパワーは、失われたSANを回復できる。
* **自己改善:** 技能が91%に達すると、その技能をマスターすることに関連する自信と規律を表し、即座に2D6 SANが回復する（これは1回限りのボーナスである）。キャラクターが最初からこの技能値以上で開始する場合、SANの増加はない。

すべての正気度の増加は完全にゲームマスターの判断に委ねられる。ゲームマスターは状況の唯一の審判であり、何が適切かを判断する。

### 状況による正気度コスト

以下の項目では、プレイ中に発生する可能性のある正気度を揺さぶる状況について説明する。ゲームマスターは追加の状況を決定する。/ の前の値はSANロールに成功した場合の量であり、もう一方はロールに失敗した場合にロールする量である。

##### 正気度損失

| SAN損失の源 | 潜在的な損失 |
| :---- | :---- |
| 不気味でグロテスクなもの、または突然の恐怖 | 0/1 |
| 小規模な不自然なクリーチャー（ゾンビ、人狼、吸血鬼など） | 0/1D3+ |
| 暴力的な死の現場、死体を見つける | 0/1D3 |
| 切断された、またはひどく傷ついた死体を見つける | 1/1D4 |
| 恐ろしい死を目撃する | 1/1D6 |
| 小規模な拷問を受ける | 1D3/1D6 |
| 現実を揺るがすビジョン（混沌、不自然な腐敗など） | 0/1D8 |
| 奇異で恐ろしいモンスター | 1D2+/1D6+ |
| 何らかの恐ろしい変化に悩まされる | 1D6/2D10 |
| 怪物的な異星の神々 | 1D10/1D100 |

同じSAN損失源に複数回遭遇した場合、ゲームマスターは後の露出の影響を軽減する（複数回の露出が合計可能な最大ロールに追加されることのみを許可するなど）か、キャラクターがSANを害する経験に慣れたり脱感作されたりしている場合は、再ロールの必要性を無視してもよい。
