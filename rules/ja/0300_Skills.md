# 3\. スキル

プレイ中、キャラクターは多くの決断を下し、困難に立ち向かい、数々のタスクを成し遂げなければなりません。最も重要な行動は、キャラクターが試みることのできる**スキル**として定義されています。このセクションでは、最も一般的なスキルを列挙し、それらを定義し、キャラクターがプレイ中に挑戦できるタスクと関連付けています。

## スキルの定義

スキルは、特定の知識と適性のセットを表します。すべてのスキルは0から100（またはそれ以上）のパーセンテージで評価されます。これを**スキルレーティング**と呼びます。数値が高いほど優れています。

本書のスキルリストは網羅的なものではありません。ゲームの種類によって追加のスキルが必要になる場合があり、ゲームマスター（GM）は必要に応じて新しいスキルを作成することが推奨されます。また、GMの判断で、スキルの名称変更、再分類、一部の削除、新しい専門分野（後述）の追加や削除を行っても構いません。

### スキルの専門分野

多くのスキルは広範であり、より焦点を絞った「専門分野」を定義する必要があります。例えば、「芸術」は広範なカテゴリーであるため、「描画」「絵画」「彫刻」「執筆」などの専門分野に分かれます。これらはスキル名の後ろに括弧書きで記載されます。したがって、「近接武器（剣）」と「近接武器（槍）」は、2つの異なるスキルとみなされます。GMの裁量により、キャラクターが適切な専門分野のスキルレーティングを持っていない場合、関連するスキルや専門分野のレーティングを半分（端数切り上げ）にしてスキルロールを行うことができます。

例えば、*キャラクターが「科学（天文学）」のスキルレーティングの半分を使用して、「科学（物理学）」や「科学（数学）」を必要とするスキルロールを行うことができます。これらは関連スキルだからです。しかし、GMが「科学（生物学）」や「知識（歴史）」のスキルロールを求めた場合、この天文学の知識は役に立ちません。*

### スキルの使用

キャラクターが行動を起こしたいときや、結果が不確実なタスクを成し遂げたいときは、まずその行動を宣言しなければなりません。その後、GMは適切なスキルレーティングに対するD100ロールを求めます。一般的に、D100の出目が修正後のスキルレーティング以下であればそのタスクは成功し、レーティングを上回れば失敗となります。

タスクの難易度やその他の状況的な修正によって、スキルのレーティングは上下します。難易度修正は以下の通りです：

* **自動**：ロール不要
* **易しい**：スキルを2倍にする
* **平均**：スキル修正なし
* **困難**：スキルを半分にする
* **不可能**：ロール不可、またはGMの裁量で01%のチャンス

詳細については「**アクションロールの修正**」を参照してください。修正が示されていない場合は、平均難易度のロールとみなします。

ほとんどの場合、特定の行動に対する適切なスキルは明らかです。しかし、予期せぬ状況が新しいスキルの使用法を生むこともあります。キャラクターのスキルを別の用途に応用することは推奨されますが、すべての応用はGMの承認を得なければなりません。

多くのスキルは行動指向ですが、そのスキルが管轄するタスクに関する一般的な知識も示しています。

例えば、*中世の戦士は「鑑定」スキルの代わりに「近接武器（剣）」スキルを使って剣の品質を判断するかもしれません。同様に「武道」スキルを使用して、街にある様々な道場や、その指導者（師範）について知ることができるかもしれません。*

### 秘密の、または隠されたスキルロール

GMは、あなたに結果を知られたくない場合、あるいはそもそもスキルロールが行われていること自体を知られたくない場合に、キャラクターの代わりにスキルロールを行うことができます。GMはキャラクターシートのコピーを手元に置くか、秘密のロールを行ってもプレイヤーに気づかれないように、関連するスキル（特に「目星」などの知覚スキル）の現在のランクのリストを求めておくのが良いでしょう。この方法は、失敗したロールを利用してプレイヤーを誤った方向に導くために有効です。

秘密裏に行われる、あるいは結果を知らされずに行われる可能性があるスキルの例は以下の通りです：「鑑定」「芸術」「交渉」「指揮」「製作」「変装」「エチケット」「言いくるめ」「ギャンブル」「隠れる」「洞察」「知識」「言語」「聞き耳」「読み書き」「医学」「操縦」「芸術（パフォーマンス）」「説得」「心理療法」「研究」「科学」「感覚」「手品」「目星」「地位」「隠密」「戦略」「教える」「技術系スキル」「追跡」。状況に応じて他のスキルが秘密裏に使用されることもあります。

これらのロールは完全に秘密である必要はなく、GMは特定のスキルに対してロールが行われることをプレイヤーに伝えても構いません。プレイスタイルに応じて、GMとプレイヤーは、GMスクリーンや遮蔽物の向こう側など、出目が見えない場所でロールを行うことも可能です。

スキルが成功した場合、GMはキャラクターがスキルを正常に使用できたことを伝え、可能であれば経験値チェックを許可すべきです。スキルロールが失敗した場合、GMは結果を伝える、誤った情報を伝える、あるいは状況に応じて結果を伝えない、といった対応をとります。

## スキルカテゴリー

スキルは6つのカテゴリーに分けられます：

* **戦闘**スキル：武器や戦闘操作の習熟度を測定します。
* **コミュニケーション**スキル：会話、読書、対人交流を司ります。
* **操作**スキル：正確な手と目の協調を必要とするタスクを定義します。
* **メンタル**スキル：特定の知識や個人の判断力を測定します。
* **知覚**スキル：環境から情報を収集・解釈します。
* **物理**スキル：筋力、敏捷性、運動能力を司ります。

スキルカテゴリーは、スキルがどのような行動を達成できるかの一般的なガイドとして機能するほか、GMとプレイヤーが新しいスキルを作成するためのフレームワークを提供します。オプションルールである「カテゴリーボーナス」を通じて、キャラクターのスキルレーティングを、最も影響力のある能力値と結びつけることができます。

### 新しいスキル

キャラクターシートのスキルセクションには空行があります。これはプレイヤーやGMが作成する新しいスキルのためのものです。例えば、『第4章：能力』では、多くの能力と組み合わせて使用する「投影」というオプションの新しいスキルが導入されています。新しいスキルを提案・定義することはできますが、ゲームでの使用を許可できるのはGMのみです。

### スキルリストの変更

GMやプレイヤーが新しいスキルを作成するのと同じくらい簡単に、設定に合わせてスキルの名称を変更することも可能です。例えば、中世やファンタジーの設定では「精密操作」を「工夫」や「鍵開け」と改名することができます。また、GMのプレイスタイルに合わないスキルを完全に排除することも可能です。このような変更はキャラクター作成前に行い、明確にしておくことを強く推奨します。そうすることで、GMによって却下されたり変更されたりする可能性のあるスキルを選択せずに済みます。

> ### スキルカテゴリーボーナス
>
> 「**スキルカテゴリーボーナス**」で説明されているように、キャラクターは能力値に基づいてスキルカテゴリーにボーナスやペナルティを受け取ります。各スキル説明に記載されている基本成功率に加え、そのカテゴリーの全スキルにカテゴリーボーナスを適用してください。算出式については「**スキルカテゴリーボーナス表**」を参照してください。

## 基本成功率

健全で体力のある一般的な人間なら、棍棒を振ったり、木に登ったり、母国語を話したりできます。したがって、すべてのスキルには基本成功率が設定されています。キャラクターは、スキルポイントを追加する前に、この基本レーティングを持っているとみなされます。スキルカテゴリーボーナスを使用する場合は、各スキルの基本成功率にそれを加算（または減算）してください。

スキルの基本成功率は、キャンペーンの時代設定に大きく依存します。例えば、中世ヨーロッパを舞台にしたキャンペーンのキャラクターは「知識（宗教）」の基本成功率が高く、現代の米国市民は学校での初歩的な応急処置訓練により「医学」スキルにアドバンテージを持つかもしれません。各スキル説明には、時代に応じた複数の基本成功率が記載されています。GMは設定に合わせて基本成功率を変更することを躊躇しないでください。

> #### スキルなしでの行動
>
> キャラクターがスキルレーティング0%のスキルを使用して行動しなければならない場合があります。そのタスクの達成が可能だとGMが判断した場合、以下のいずれかのオプションでロールを行います：
>
> * **スキルカテゴリーボーナス：** オプションのスキルカテゴリーシステムを使用している場合、カテゴリー修正値を基本成功率として使用します。天性の才能が訓練不足を補うことがあります。成功し、かつ経験によってスキルが向上する余地がある場合は、経験値チェックを行うべきです。
>
> * **無謀な挑戦：** 挑戦はしますが、成功率はわずか1%です。または、GMの承認がある場合に限り、POW×1の幸運頼みのロールを行うこともできます。これは純粋な運であり、スキルや天賦の才とは異なるため、経験値チェックは行われません。

### スキルレーティングの測定

キャラクターのスキルレーティングは、プレイ中の能力を定義します。では、特定のスキルレーティングは一般的な言葉で何を意味するのでしょうか？習熟度のガイドラインとして以下を使用してください。特定のスキルランクにおいて、かつ非決定的または非劇的な状況下では、ロールが必要ない場合もあります。ルーチン的な状況では、一定の能力レベルを持つキャラクターはロールをせずにそのスキルを定期的に実行できますが、*自動的*な成功には経験値チェックの権利はありません。

##### スキルレーティング表

| スキルレーティング | 習熟度 | 説明 |
| :---- | :---- | :---- |
| 00–05% | 初心者 | 易しいタスクさえ成功させる希望がほとんどない完全な素人。ストレスの多い状況か理想的な状況かに関わらず、キャラクターがこのスキルを試みるたびにロールすべきです。 |
| 06–25% | 入門者 | 初心者、または対象分野についてわずかな知識を持つ人。「生兵法は怪我の元」という状態。たまに成功し、その結果自信過剰になることがあります。易しいタスクであっても、キャラクターが試みるたびにロールしてください。 |
| 26–50% | アマチュア | 多少の才能、いくらかの訓練、趣味レベルの経験がある人。かろうじて資格がある程度ですが、自動または易しいタスクは任せられます。ストレスのない状況であれば、キャラクターはロールなしでルーチン的な活動を行えます。 |
| 51–75% | プロ | 51%あれば、そのスキルを使って生計を立てることができます。通常、易しいタスクの失敗を心配する必要はなく、他者のリーダーやマネージャーを務めるのに十分な経験を持っています。51%は、特定の分野の学士号にほぼ相当します。ほとんどのスキルは教育や訓練だけでは75%を超えられません。キャラクターは実務を通じてさらに成長する必要があります。通常、スキルに関連するルーチン的または複雑な活動を行うことができ、リスクがある場合や失敗が劇的な結果をもたらす場合にのみロールが求められます。 |
| 76–90% | エキスパート | その分野における高度な専門知識：キャラクターは困難なタスクでも成功する可能性が十分あります。専任のプロフェッショナルのみがこのレベルの習熟に達し、彼らはその専門知識によって尊敬され、頼りにされます。この範囲のスキルは、大学院修士号や博士号、あるいは長年の経験に相当します。ほとんどの平均的なキャラクターは、開始時に75%を超えるスキルを持つことはできません。適切な施設や装備があれば、ルーチン的な状況で複雑で困難なアクションをロールなしで実行できるはずです。 |
| 91%以上 | マスター | この習熟レベルに達する者は稀です。最も困難なタスク以外は彼らの能力範囲内であり、その専門知識は分野内、あるいは世界中で彼らを有名にしているでしょう。ルーチン的な状況では奇跡に近いパフォーマンスができ、最も困難なタスクや極限状況以外でダイスを振る必要はほとんどありません。キャンペーンで「正気度」ルールを使用している場合、スキルで91%に達すると、即座にSANポイントを2D6回復します。これは習熟に伴う自信と規律を表すボーナスです（一度限り）。開始時点でこのレーティング以上であっても、SANの増加はありません。 |

### 100%を超えるスキルレーティング

キャラクターの経験ボーナスにより、スキルレーティングを100%以上に高めることが可能です。100%を超えるスキルは、スペシャル成功やクリティカル成功の確率を計算する標準システムを使用するほか、困難なタスクや負の修正がかかる状況でも高い成功率を提供します。さらに、戦闘スキルが100%を超えるキャラクターは、「**100%を超える攻撃と受け流し**」で説明されているように、戦闘ラウンド中に複数の攻撃を行うことができます。

> ### 補助と補完スキル
>
> 一部のスキルは他と密接に関連しており、一方の分野での専門知識がもう一方に利益をもたらすことがあります。GMの許可があれば、キャラクターはロールの際、**補完スキル**のレーティングの1/5を一時的に他のスキルのレーティングに加算できます。多くの補完スキル使用例は、以降のスキル説明に記載されています。プレイヤーたちは間違いなくさらなる応用を見出すでしょう。
>
> 1回のロールを補助するために使用できる補完スキルは、1つだけです。複数のスキルが適用可能であっても、ボーナスは累積しません。プレイヤーとGMは、最も適切と思われるものや、最大のボーナスを選択してください。
>
> メインのスキルロールが成功した場合、キャラクターはメインスキルに対してのみ経験値チェックを受けることができ、補完スキルには受けられません。
>
> 例えば、*キャラクターが「医学」65%と「科学（薬学）」40%を持っているとします。彼らは病人を治療しようとしています。十分な医療品と薬品があれば、「科学（薬学）」レーティングの1/5である8%を「医学」スキルレーティングに加え、修正後の73%として使用できます。彼らはさらに「応急手当」や「科学（生物学）」の1/5を加算することはできません。この場合、GMは「科学（薬学）」が最も適切な補完スキルであると裁定します。*
>
> スキルに対する**増幅**は同様ですが、少し異なる働きをします。GMが許可すれば、メインのスキルロールをサポート（増幅）するために、補完スキルでロールを行うことができます。
>
> * 増幅スキルロールが成功すれば、メインスキルの難易度を1段階調整できます（例えば「困難」を「平均」に、「平均」を「易しい」にするなど）。
> * これは補完スキルボーナスと同時に行うことはできず、調整は1段階のみです。
> * 増幅が失敗した場合、混乱や情報の競合により、メインスキルは逆方向に1段階調整されます（例えば「平均」が「困難」になる）。
> * 増幅スキルロールが成功すれば、メインスキルと同様に経験値チェックを行うことができます。メインのロールが失敗した場合、増幅スキルには経験値チェックは与えられません。
>
> 1回のスキルロールに対して、スキル増幅と補完スキルボーナスを同時に使用することはできません。

> ### 成功結果の記述
>
> 一般的にスキルロールの結果は明らかですが、迷った場合は以下のガイドラインを使用して結果を判断してください：
>
> * **ファンブル**は通常、望む結果の逆が起こることを意味し、誤った情報の提供、何らかの挫折、あるいはキャラクターを不利な立場に置くことを指します。
> * **失敗**は、望む結果が得られなかったことを意味します。
> * 通常の**成功**は、合理的かつ平均的な目標が達成されたことを意味します。結果の最終的な決定権はGMにありますが、効果は明白であるべきです。
> * **スペシャル成功**は、通常の成功の2倍の効果を発揮するか、主題に関する追加情報を提供します。
> * **クリティカル成功**は、通常の成功の3倍の効果を発揮するか、主題に関するかなりの情報を提供します。
>
> 前述の通り、結果が非常に具体的で詳細な記述を必要とするスキルについては、定義された結果が維持されています。

## スキル説明

網羅的なアルファベット順のスキルリストが続きます。各エントリーには以下の情報が含まれます：

* **スキル名：** スキルの名称。
* **基本成功率：** すべてのキャラクターが持つ基本レーティング（必要に応じて時代別）。
* **カテゴリー：** 一般的な分類やオプションのカテゴリーボーナスのためのスキルカテゴリー。
* **説明：** スキルを使用して達成できるタスクの簡単な説明。
* **専門分野：** スキルに固有の専門分野のリスト（ある場合）。
* **効果：** 必要に応じて、成功の度合いごとのスキルロール結果。簡単に言えば、ファンブル（最悪の結果、通常は99または00）、失敗（スキルレーティングを超える）、成功（スキルレーティング以下）、スペシャル成功（スキルレーティングの1/5以下）、クリティカル成功（スキルレーティングの1/20以下）です。『第5章：システム』で詳細を説明しています。「成功結果の記述」サイドバーも参照してください。
* **設定メモ：** 異なる設定におけるスキルの補足情報。この項目がない場合、スキルはほぼどの設定でも変わらず動作します。
* **システムメモ：** 関連するルールやシステム（ある場合）。

### 鑑定

**基本成功率：** 15%

**カテゴリー：** メンタル

古い絵画、宝石、武器、馬など、物体の価値を見積もるために使用します。失敗すると価値がわからず、ファンブルすると誤った情報が得られます。スペシャルやクリティカル成功では追加情報が得られます。

### 芸術（各種）

**基本成功率：** 05%

**カテゴリー：** 操作

絵画や彫刻で芸術作品を作ったり、物語、詩、音楽を作曲したりするために使用します。クリティカルやスペシャル成功では、より価値と名声のある時代を超越した名作が生まれ、失敗は平凡な駄作となり、ファンブルすると作成者の評判を傷つける可能性があります。演技、ダンス、歌唱、楽器演奏には「芸術（パフォーマンス）」を使用してください。

**専門分野：** 書道、作曲、コンセプチュアル・アート、デジタルアート、描画、絵画、写真、詩、彫刻、スケッチ、作詞作曲、執筆など。

**設定メモ：** 芸術は普遍的ですが、時代や設定固有の専門分野がある場合があります。

### 火砲（各種）

**基本成功率：** 武器専門分野に準ずる

**カテゴリー：** 戦闘

大砲、投石機、バリスタなど、単独では移動や操作ができないような巨大な火砲や重火器を発射するために使用します。

**専門分野：** 専門分野は武器の種類に相当します。『第8章：装備』の「武器クラス」を参照してください。

**効果：** 特定の効果については、「攻撃と防御マトリックス」および「遠隔武器ファンブル表」を参照してください。

**設定メモ：** 攻城兵器から現代または未来の火砲や車両兵器まで、多くの設定に適しています。ほとんどの設定では、このスキルを習得するために軍事的背景が必要です。

**システムメモ：** 多くの大型武器は運用にクルーを必要とし、一人で使用しようとすると「困難」または「不可能」になります。装填と準備に複数ラウンド、あるいはターンを要する場合があります。多くの大型武器は連射や爆発性弾薬を使用します。「連射」および「爆発」を参照してください。すべての弾はどこかに着弾します。爆発やエネルギー弾が外れた場合、GMはどこに影響が出るかを決定すべきです。

### 交渉

**基本成功率：** 05%

**カテゴリー：** コミュニケーション

価格交渉や、意見が対立する場での交渉と妥協のために使用します。重要な取引には対抗ロールを使用し、些細な試み（装備や宿泊費の節約など）には単純なスキルロールを使用します。交渉とは妥協点を見出すことです。勝ち負けがはっきりしている議論を解決するには「言いくるめ」や「説得」を使用してください。ファンブルすると商人を敵に回す可能性があり、成功すれば取引が成立し、より良い結果が出れば割引率や有利な条件を得られます。

### 格闘

**基本成功率：** 25%

**カテゴリー：** 戦闘

素手での戦闘（キック、パンチ、頭突きなど）に使用します。

**効果：** 「攻撃と防御マトリックス」および「肉弾攻撃・受け流しファンブル表」を参照してください。

**システムメモ：** 格闘は「受け流し」に使用できますが、成功しても受け流した腕や脚には最低限のダメージを受けます。組付き状態の敵に対して格闘を使用するのは「易しい」です。「武道」や『第4章：能力』の「肉体武器」や「素手戦闘」能力と併用します。

### 登攀

**基本成功率：** 40%

**カテゴリー：** 物理

壁、木、崖などの表面を登り降りするために使用します。十分な手足の掛かり場があると仮定されます。表面状態に応じて難易度を修正してください。ファンブルすると激しく落下し（「転落」を参照）、失敗するとその場に立ち往生するか落下します（GMの裁量）。より良い成功では、より速く遠くまで登ることができます。

**システムメモ：** 一般的に登攀速度は移動速度の1/5であり、自然な登攀能力を持つ動物は全速度で移動できます。梯子を登るのは「自動」です。非常に背の高い梯子や木は「易しい」です。足を使わずに登るのは「困難」です。長時間の登攀では、GMは1分ごと、または10メートルごとにスキルロールを求めるべきです。登攀中は他のアクションは取れず、登攀中に行うすべてのアクションは「困難」となり、ファンブルすると落下します。

### 指揮

**基本成功率：** 05%

**カテゴリー：** コミュニケーション

部下を鼓舞・指示し、複雑なタスクを調整してグループの効率を改善するために使用します。軍の士官、貴族、政治家、ビジネスエグゼクティブは、管理・統率能力が評価されます。性格、力強い声、鉄の意志が貴重な道具となります。ファンブルすると暴動を煽る可能性があり、失敗すると士気を下げ混乱を招きます。成功すれば、命令に従う部下全員に対して、指揮するラウンドごとに「指揮」スキルの1/5を補完スキルボーナスとして付与できます。戦闘では毎ラウンド、集団戦闘では毎ターンロールしてください。

**システムメモ：** 主に戦闘で使用されますが、企業交渉などにも拡張可能です。火砲、重火器、近接武器、遠隔武器、戦略スキルがこの恩恵を受けるのに最も適しています。

### 製作（各種）

**基本成功率：** 05%

**カテゴリー：** 操作

椅子から食事、家まで、物を作るために使用します。専門的な道具が必要なことが多く、時間と原材料を要します。また、物体がどのように作られたかを特定したり、作成者を特定したりするためにも使えます。ファンブルすると材料を台無しにし、成功すれば完成し、より良い品質の成功では、より頑丈で価値の高いもの（効率に+10%や+20%のボーナス、HPが高いなど）ができます。これは機能や実用性に関するもので、純粋に美学を目的とした製作は「芸術」に分類されます。

**専門分野：** 鍛冶、大工、陶芸、料理、革細工、錠前開け、冶金、石工など。

**システムメモ：** 適切な道具なしで製作を行うのは「困難」です。装備の製作・修正・修理については『第8章：装備』を参照してください。上質な衣服や装備品を所有していると、それを着用・披露している間、CHAが増加する可能性があります。

### 解体

**基本成功率：** 01%

**カテゴリー：** 操作

火薬樽からダイナマイト、火炎瓶、高性能プラスチック爆薬、反物質爆弾まで、爆発物の保管、輸送、設置、起爆に使用します。単に爆弾を爆発させるだけなら誰でもできます。これは爆破によって建物を安全に倒壊させたり、橋を破壊したり、金庫の中身を傷つけずに扉を吹き飛ばしたりといった、特定の効果を得るためのスキルです。導火線や起爆装置などの知識も含みます。科学（化学）を使用して爆発性化合物を製造したり、技術系スキルで爆発物を作成したりします。ファンブルすると爆発に巻き込まれ、失敗すると効果が出ず（不発）、優れた成功ではダメージの増加や付随被害の軽減、ノックバックなどの特殊効果が得られます。

**システムメモ：** スキルレーティングが60%以上あれば、通常の解体は自動成功します。不安定な爆発物（発汗ダイナマイトなど）は扱うたびにロールを要求される場合があります。大規模な構造物（橋、ダム、バンカーなど）の解体は、設計図がなければ「困難」です。適切な道具なしでの使用や、専門外の爆発物の使用は「困難」または「不可能」です。手榴弾などはこのスキルなしで使用できる場合があります。爆発物とその効果については『第8章：装備』を参照してください。

### 変装

**基本成功率：** 01%

**カテゴリー：** コミュニケーション

姿勢、衣装、声、その他のトリックを使用して、別人や別の種類の人間に見えるようにします。薄暗い照明、演劇用メイク、大幅な顔の変更（髪型やかつら、付け髭など）はGMの裁量で+20%のボーナスになります。変装したキャラクターを詳しく調べる、あるいは会話を交わした観察者は、キャラクターの変装ロールに対して対抗「目星」や「洞察」を行い、策略を見抜くことができます。変装したキャラクターが会話で観察者を引き付け、注意をそらすことができれば、「言いくるめ」を使って対抗ロールを行うことができます。ファンブルすると明らかにバレ、失敗すると二度見した人には騙せず、優れた成功では騙している相手に対するコミュニケーションロールに補完ボーナスを得たり、探知をより困難にしたりします。

**システムメモ：** 特定の種類の人（兵士、警官など）への変装は通常の行動です。全く異なる人間（異なる種族、身長、性別）や、有名な特定の個人（貴族、有名人など）への変装、あるいは適切な服や小道具なしでの変装は「困難」です。GMは文化的・言語的な壁がある場合や、複数の困難な条件が重なる場合にさらなるペナルティを科すことができます。あまりに無理な変装は単に「不可能」です。

### 回避

**基本成功率：** DEX×2

**カテゴリー：** 物理

戦闘において、攻撃を受けないことが最大の防御です。回避により、キャラクターは agility を駆使して incoming 攻撃を避けたり、最小限に抑えたりできます。

**効果：** 回避ロールの成功は、攻撃側の成功結果を修正し、失敗に転じます。スペシャル成功は攻撃を2段階修正し、クリティカル成功は3段階修正します（クリティカル攻撃を失敗に変える）。「攻撃と防御マトリックス」および「肉弾攻撃・受け流しファンブル表」を参照してください。回避成功は、 incoming 攻撃の結果を「失敗」未満にはできません。

**システムメモ：** 『第6章：戦闘』の「回避」で説明されているように、キャラクターは戦闘ラウンド中に回避または受け流しのどちらかを行えますが、両方は行えません。多数の敵に攻撃された場合、ラウンド中に複数回回避を試みることができますが、2回目以降のロールには累積-30%のペナルティがかかります。一部の遠隔攻撃は「困難」または「不可能」です（「遠隔武器の回避」を参照）。

### 運転（各種）

**基本成功率：** 20% または 01%（後述）

**カテゴリー：** 操作

動物に引かれるものからエンジン動力のものまで、陸上車両を操縦・制御するために使用します。一般的な車両は20%、未知の・珍しい車両は01%です。ファンブルするとエンジンがかからない、あるいは衝突・転覆します。成功すれば目的地に着く、あるいはスリップやスピンなどの悪状況を修正できます。より優れた成功では、より短い時間で距離を稼いだり、燃費を抑えたりできます。

**専門分野：** 自動車、自転車、馬車、カート、戦車（チャリオット）、犬ぞり、バイク、トラック、橇など。

**設定メモ：** 必要に応じてユーザーの馴染み具合で基本成功率を調整しますが、迷ったら基本原則が適用されると仮定してください。

**システムメモ：** 日常的な運転は「自動」のタスクです。運転ロールが必要なのは、悪条件下や特別な状況（混雑した市街地でのスピード走行、カーチェイスなど）のみです。気づかれずに他車を追跡するには、相手ドライバーの「目星」と対抗する運転ロールを使用します。車両チェイスの解決については「チェイス」を参照してください。

### エネルギー武器（各種）

**基本成功率：** 武器専門分野に準ずる

**カテゴリー：** 戦闘

レーザー、ブラスター、ディスラプターなど、手持ちの指向性エネルギー兵器やビーム兵器を発射するために使用します。

**専門分野：** エネルギーピストル、エネルギーライフルなど。専門分野は武器の種類に相当します。『第8章：装備』の「武器クラス」を参照してください。

**効果：** 「攻撃と防御マトリックス」および「遠隔武器ファンブル表」を参照してください。エネルギー武器は通常、貫通します。

**設定メモ：** エネルギー武器は通常、未来的な設定にのみ登場します。それらがない文化の人間は、それを使用する方法を理解するために「困難」な「アイデア」ロールを行う必要があり、かつ見たことがなければならないかもしれません。失敗やファンブルは武器やユーザーにとって悲惨な結果を招く可能性があります！このスキルを習得するには軍事的背景が必要な場合があります。

**システムメモ：** 一部のエネルギー武器には、使用するための最低STRとDEX要件があります（『第8章：装備』の武器表を参照）。エネルギー武器はダメージボーナスを使用しませんが、狙いを定めた攻撃に使用できます。回避はできませんが、標的の移動や向きによって射撃にペナルティが課される場合があります（「遠隔武器の回避」を参照）。盾スキルでエネルギー弾をブロックするのは「困難」です。

### エチケット（各種）

**基本成功率：** 05%

**カテゴリー：** コミュニケーション

ほとんどの文化、階級、グループには社会的ルールと行動規範があります。適切な服装、話し方、特定の行動、ボディランゲージ、さらには決闘による裁判などがグループのエチケットの一部となり得ます。ヴィクトリア朝の晩餐会、重要な就職面接、あるいは犯罪組織への加入など、キャラクターが適切に振る舞う必要があるときはいつでもこのスキルを使用してください。エチケットロールは重要なNPCとの謁見を得たり、相手の社会的モラルに関する知識で他者を感銘させたりする可能性があります。ファンブルは致命的な失礼を表し、失敗は印象を与えず、成功以上では優れた結果が得られ、受け入れられ方が改善されます。

**専門分野：** グループ別。二つ目のグループの作法を学ぶには、その専門分野のエチケットスキルを習得する必要があります。

**システムメモ：** GMは重要な状況でのみエチケットロールを求めるべきです。例：重要なグループとの初対面、重大な行事、グループ内での地位向上を試みる時など。

### 言いくるめ

**基本成功率：** 05%

**カテゴリー：** コミュニケーション

セールスマン、スパイ、詐欺師が好む武器です。相手が信じていないかもしれないことを素早く納得させたり、判断を急がせたりするために使用します。ドアマンをやり過ごしたり、強引な売り込みを短時間で行うために使います。言いくるめは使用が早く、通常は一時的な効果です。数分後に「アイデア」ロールを行い、相手が正気に戻る可能性があります。相手の考えを本気で変えるには「交渉」や「説得」スキルを使用してください。ファンブルすると敵意を招くことがあり、失敗は徒労に終わり、成功以上では効果が高まるか、あるいは意見を永続的に納得させることができます。

**システムメモ：** 優れたロールプレイや説得力のある議論は言いくるめを「易しい」にする可能性があり、逆もまた然りです。「交渉」「言いくるめ」「説得」の最初の試みに失敗した後で同じターゲットを言いくるめようとするのは「困難」です。

### 精密操作

**基本成功率：** 05%

**カテゴリー：** 操作

手先の安定性と手目の協調性を測定するスキルで、手や指を注意深く使うあらゆる行動をカバーします。鍵開け、罠の解除、結び目の結び解き、機械装置の分解などに使用します。ファンブルすると失敗し、対象を壊したり詰まらせたりする可能性があります。優れた成功では時間を短縮したり、将来的に容易にしたり、改ざんの痕跡を残さないといったメリットがあります。

**システムメモ：** 必要な専門道具なしでこのスキルを使用するのは「困難」です。

### 火器（各種）

**基本成功率：** 武器専門分野に準ずる

**カテゴリー：** 戦闘

火器の命中精度を測定し、取り扱い、メンテナンス、基本的な修理の習熟度を提供します。

**専門分野：** 機関銃、ピストル、リボルバー、ライフル、ショットガン、サブマシンガン。専門分野は武器の種類に相当します。『第8章：装備』の「武器クラス」を参照してください。

**効果：** 「攻撃と防御マトリックス」および「遠隔武器ファンブル表」を参照してください。火器は通常、貫通します（詳細については『第8章：装備』を参照）。

**設定メモ：** 火器に不慣れなキャラクターは、使用している姿を見たことがなければ、使い方を理解するために「困難」な「アイデア」ロールを行う必要があります。失敗やファンブルは武器やユーザーにとって悲惨な結果を招く可能性があります！

**システムメモ：** 一部の火器には最低STRとDEX要件があります（『第8章：装備』を参照）。火器はダメージボーナスを使用せず、狙いを定めた攻撃に使用できます。

### 応急手当

**基本成功率：** 30%

**カテゴリー：** メンタル

出血の停止、傷や軽度の火傷の包帯、骨折の固定、溺水者の蘇生、気絶した人の意識回復に使用します。トリアージや初歩的な医療ケアにも及びますが、毒、病気、微妙な身体的疾患には効果がほとんどありません。これらは「医学」スキルで治療する必要がありますが、GMが緊急治療として「困難」なロールを許可する場合もあります。応急手当は1戦闘ラウンドを要し、通常、戦闘中には実行できません。中断された場合、最初からやり直す必要があります。

**効果：** 応急手当には特定の結果があります：

* **ファンブル：** 患者は1の一般的HPダメージを受け、状態は変わりません。
* **失敗：** 効果なし。以降の応急手当は行えません。
* **成功：** 以下のいずれかを選択（プレイヤーが選択）：
    * 単一の傷や怪我のHPを1D3回復。
    * HPが0またはマイナスのキャラクターを、1+まで回復させて蘇生。
    * 気絶したキャラクターの意識回復。
    * 出血によるダメージや、その他の継続的な部位ダメージの停止。
* **スペシャル成功：** 上記と同様ですが、2D3 HP回復。
* **クリティカル成功：** 上記と同様ですが、3+1D3 HP回復。

**システムメモ：** 各傷に対して応急手当を使用できるため、傷ごとに管理してください。1つの傷につき1回のみ試行可能です。危険、または非衛生的な状況ではロールが「困難」になる可能性があります。キャラクターは「医学」の1/2と「科学（薬学）」の1/5を一時的なボーナスとして加算できます。現代の医療機器（鎮痛剤、包帯、薬品など）は+20%のボーナスを与え、未来的な医療技術（人工スプレースキン、医療スキャナー、ナノヒーラー）はすべての応急手当を「易しい」にします。

### 飛行

**基本成功率：** DEX×4 または 1/2 DEX（後述）

**カテゴリー：** 物理

翼を持つ存在、適切な装備（反重力ベルト、ロケットブーツなど）、あるいは飛行能力を持つ存在が、乗り物なしで空中を操縦するために使用します。空中でコントロールを失わずに空中機動やアクロバットを行ったり、空中戦闘で敵を翻弄したり、悪天候下で飛行したりします。基本成功率は翼を持つ生物はDEX×4、その他は1/2 DEXです。ジェットパック、ハンググライダーなどは「パイロット」スキルを使用します。詳細は「空中戦闘」および「チェイス」を参照してください。

**効果：** 飛行には特定の結果があります：

* **ファンブル：** 失速し、転落する可能性があります。翼を持つキャラクターは「耐久力」ロールに成功しないと、捻挫や筋違いで1D3-1のダメージを受けます。装置は失速・故障し、キャラクターを浮かせ続けられません。飛行者は地上高のレベルごとに1ラウンド落下します。滞空するために「困難」な飛行ロールを行ってください。失敗すると墜落します（「転落」を参照）。
* **失敗：** 進路から外れるか、望ましくない高度へ降下。どこにも進めない。
* **成功：** 望む機動を完了、またはチェイス中で位置を維持。
* **スペシャル成功：** 望む機動を完了し、空中戦闘での次の回避、飛行、または攻撃ロールに+10%のボーナス。
* **クリティカル成功：** 望む機動を完了し、空中戦闘での次の回避、飛行、または攻撃ロールに+25%のボーナス。

**システムメモ：** 通常または穏やかな条件下での短時間の飛行は「自動」です。天候条件による飛行への修正を参照してください。「耐久力」ロールは長距離飛行に必要であり、4時間ごとに係数が1ずつ減少します。通常の飛行は疲労ポイントを消費しませんが、機動やストレスの多い飛行は激しい活動です。鎧や重装備を着用しての飛行は、ENCの合計に等しいペナルティを受けます。重い物を運んでいる飛行キャラクターは、浮き続けるために自分のSTRと、運んでいる物のSIZを抵抗表で競わせる必要があります。

### ギャンブル

**基本成功率：** INT+POW%

**カテゴリー：** メンタル

チェスやバックギャモンから、カードやダイス、その他のランダム性や戦略性を含む賭け事まで、ゲーム中に使用します。ギャンブラーはこのスキルで生計を立てていますが、他の人にとっては単なる娯楽です。ファンブルすると全財産を失い、借金を抱える可能性があり、失敗するとラウンドに負け、成功すれば少額の勝ちを得、より良い結果では大きな利益を得、地位が向上するかもしれません。

**システムメモ：** スキルと戦略が一部を占めるゲームの解決に使用し、他のプレイヤーが対抗ロールを行います。不正を行うには「手品」または「言いくるめ」を使用し、「観察」または「洞察」で対抗されます。完全にランダムな結果には幸運ロールを使用します。

### 組付き

**基本成功率：** 25%

**カテゴリー：** 戦闘

相手を傷つけずに制圧することを目的としたレスリングや戦闘に使用します。通常は非致死的ですが、実際にダメージを与えるためにも使用できます。

**効果：** 組付きには特定の結果があります：

* **ファンブル：** 「肉弾攻撃ファンブル表」でロールしてください。
* **失敗：** 標的が回避する、または脱出が失敗する。
* **成功：** 標的に組付き成功。ホールドを維持すれば、次ラウンドに組付き効果（下記参照）を1つ適用可能。
* **スペシャル成功：** 次の組付き維持ロールが自動成功し、組付き効果の抵抗ロールに+3のボーナス。
* **クリティカル成功：** 次の組付き維持ロールが自動成功し、その戦闘ラウンド中、標的の組付き効果に対する抵抗ロールの能力値が半分になる。

**システムメモ：** 攻撃者は標的をホールドするために組付きを成功させる必要があります。成功すればランダムな部位を掴みます（部位ルール使用時）。組付きは組付きスキルで受け流せます。武器や盾で受け流した場合、組付きが成功すれば攻撃者は武器や盾を持っている腕を自動的に掴みます。ホールド確立後、毎ラウンド維持のために組付きロールに成功しなければなりません。組付き効果以外の行動を取るとホールドは解除されます。ホールド状態でも、自由な腕があれば格闘や小さな武器（ナイフやハンドガン）で攻撃可能です。両手が自由なら、標的は組み返しを試みられます。

複数の攻撃者が一人の標的に組付くことができますが、一つの部位を掴めるのは最大2人までです。競合テストでは両攻撃者のSTRを合算します。

> ### 組付き効果
>
> ホールドに成功した攻撃者は、組付きが成功した次ラウンドから、毎ラウンド1つの効果を試行できます。特定の部位を掴んでいる場合にのみ使用できるものがあります（下記参照）。部位ダメージルールを使用している場合、GMは結果を解釈する必要があるかもしれません。
>
> * **ホールドの変更（任意）：** 抵抗表でDEX同士を競わせます。成功すれば、攻撃者はホールド部位を別の場所へシフトできます。失敗してもホールドは維持されます。
> * **武器の武装解除（腕）：** 抵抗表で攻撃者のSTR+SIZ vs 標的のSTRを競わせます。攻撃者が成功すれば、標的は手に持っているものを落とし、腕は固定されたままになります。
> * **二か所目のホールド（腕/脚）：** 別の部位を掴もうと試みます。抵抗表で攻撃者のDEX vs 標的のDEX+SIZを競わせます。成功すれば追加で掴めます。
> * **部位の固定（腕/脚）：** 抵抗表で攻撃者のSTR vs 標的のSTRを競わせます。成功すればホールドが解除されるまでその部位では何もできません。
> * **ダメージを与える（頭/胸/腹）：** 肘打ちや締め上げなどで、標的に1D3 +ダメージボーナスのダメージ（一般ダメージまたは部位ダメージ）を与えます。標的は即座にSTR対抗で脱出を試みられます。
> * **全身の固定（頭/胸/腹）：** 抵抗表で攻撃者のSTR vs 標的のSTRを競わせます。成功すればホールドが解除されるまで何もできません。
> * **ノックダウン（頭/胸/腹）：** 攻撃者が標的を倒し、強制的に伏せ状態にします。標的は敏捷性ロールを行わないと1ダメージを受けます。
> * **絞殺（頭）：** 標的は毎ラウンドCON×1%ロールを行わないと1D3の一般ダメージを受けます。標的は即座にSTR対抗で脱出を試みられます。一度始めると維持のためのロールは不要です。
> * **投げる（特殊）：** 抵抗表で攻撃者のSTR+DEX vs 標的のSIZ+DEXを競わせます。投げるとホールドは解除されます。攻撃が成功すれば標的は1D6メートル投げられ、自動的にノックダウンし、敏捷性ロールを行わないと1D6のダメージを受けます。DEX×1%で着地可能です。

### 重機械（各種）

**基本成功率：** 01%

**カテゴリー：** 操作

フォークリフト、戦車、ブルドーザー、クレーン、機関車、大型船のエンジンなど、人より大きく移動バンよりも重い車両や機械を操作するために使用します。基本的なケアや予防メンテナンスも含まれますが、故障時は修理スキルが必要です。航空機にはパイロットを使用します。ファンブルするとクラッシュ、エンジン故障、財産被害を招き、失敗すればタスクを完了できません。優れた結果では高い効果が得られます。

**専門分野：** 車両タイプ別（装甲車両、ボイラー、ブルドーザー、クレーン、エンジン、タービンなど）。

**システムメモ：** 重機械は通常チェイスには参加できませんが、武器として使用できるものがあり、サイズに応じて3D6〜6D6のダメージを与えます。極限状態での操作は「困難」です。

### 重火器（各種）

**基本成功率：** 武器専門分野に準ずる

**カテゴリー：** 戦闘

バズーカ、ロケットランチャー、重機関銃、三脚取り付け型レーザーキャノンなど、携帯性の限界を超える爆発物や大型直射武器を操作するために使用します。大砲、攻城兵器、車両取り付け型武器などは「火砲」を使用します。

**専門分野：** 武器の種類別。バズーカ、火炎放射器、ミニガン、ロケットランチャーなど。『第8章：装備』の「火砲と爆発物」を参照してください。

**効果：** 「攻撃と防御マトリックス」および「遠隔武器ファンブル表」を参照してください。重火器は通常、貫通またはノックバックします。

**システムメモ：** 多くの重火器は連射または爆発性弾薬を使用します。「連射」および「爆発」を参照してください。外れたすべてのショットはどこかに影響します。

### 隠れる

**基本成功率：** 10%

**カテゴリー：** 物理

視界から物体や自分自身を隠す技術です。追跡からの逃走、監視の回避などに使用します。ファンブルすると直ちに注意を引き、失敗すると「目星」で探される確率が「易しい」になります。成功すると相手の目星ロールが必要になり、優れた成功では「困難」または「不可能」になります。

**システムメモ：** 隠れるは観察者や捜索者の目星に対する対抗ロールです。隠れ場所が必須であり、遮蔽物が少なければ「困難」、遮蔽物が全くない（真っ昼間の平地など）なら「不可能」です。迷彩服や顔ペイントなどの装備は最高+20%のボーナスになります。環境条件もボーナスを与え得ます。可能な限り静止しているべきであり、移動しながらの使用は「困難」、1ラウンドに1メートル以上移動するには「隠れる」と「隠密」の両方のロールが必要です。隠れるは視覚・聴覚に対してのみ有効であり、熱感知センサーや鋭い嗅覚には「感覚」スキルで探知される可能性があります。

### 洞察

**基本成功率：** 05%

**カテゴリー：** 知覚

ボディランゲージ、話し方、その他の無形の要素に基づいて、他者の性格、感情状態、動機を評価するために使用します。ギャンブラーがブラフを感じ取ったり、探偵が嘘をかぎ分けたりするために使います。ファンブルは誤った情報、失敗は徒労に終わり、成功すれば標的の考えを理解でき、優れた成功では内面を深く見抜くことができます。

**システムメモ：** エチケット、言いくるめ、説得などと対抗可能です。親しい友人や家族に対しては「易しい」です。「性格特性」システムを使用している場合、洞察はその特性の強さを一般的な言葉で判断できます。

### 跳躍

**基本成功率：** 25%

**カテゴリー：** 物理

高さや距離を跳んだり、障害物を越えたりするために使用します。通常、健全な人間は立った状態から身長の水平方向の距離と身長の半分を垂直方向に、助走があれば水平方向に約3メートル跳べます。ファンブルすると転倒（1D6の一般ダメージ）、成功すれば上記通りの跳躍、スペシャル成功では距離・高さが50%増し、クリティカル成功では倍になります。落下ダメージを成功度に応じて1D6ずつ軽減できます。

**システムメモ：** その場跳びはDEXランク1を消費。助走跳びは通常の移動と同じDEXランクを使います。アクロバティックな跳躍は「困難」です。

### 知識（各種）

**基本成功率：** 05% または 00%（後述）

**カテゴリー：** メンタル

知識分野における経験や学問的研究を表します。関連する事実の想起、手がかりの特定・分析、論理的推論、感銘を与えるトリビアの想起に使用します。科学的なものについては「科学」を使用してください。ファンブルは誤った嘘を導き、成功は詳細な情報をもたらします。

**専門分野：** 会計、人類学、考古学、歴史、法律、オカルト、宗教など。専門分野が一般的であれば05%、研究を要するものは00%の基本成功率とします。

**設定メモ：** ファンタジーや歴史設定では、専門分野はごく一部に限られます。現代設定では専門分野が増えます。

**システムメモ：** オプションのEDU能力値と「知力」ロールが一般的な知識をカバーし、専門的な情報は「知識」スキルの専門分野が表します。

> ### 知識の専門分野
>
> これらは包括的ではなく、必要に応じて拡張可能です。
>
> * **学問的知識（古代のみ）：** 図書館のすべてが学問と言える時代における「教養」。ほとんどの知識分野で「知力」ロールのように使えます。
> * **会計：** 帳簿分析、財務分析（負債、倒産、資産など）、不正の特定に使用します。
> * **人類学：** 文化、習慣、芸術の学問。文化や遺物の起源、モラルや行動の特定に使用します。
> * **考古学：** 消滅した文化の学問。遺物の特定、偽物の見抜き、発掘と推論に使用します。
> * **美術史：** 様々な時代の芸術の学問。起源の特定、偽物、制作者の特定に使用します。
> * **冒涜的知識：** 恐るべきオカルト秘密と古代の悪の学問。これを持つほど正気を失います。開始時0%から始まり、経験では上昇しません。
> * **ビジネス：** 起業、ギルド規定、企業法、管理術の学問。プレイヤーや経済トレンドの予測に使用します。
> * **スパイ活動：** Spy組織、方法論、著名な工作員の学問。暗号解読は科学（暗号学）を使用します。
> * **民俗学：** 習慣、物語、寓話の学問。伝承や伝説の特定に使用します。
> * **グループ/サブ：** 特定の文化や社会階級に関する一般情報。メンバーの特定や誰が誰であるかの想起に使用します。
> * **歴史：** 過去の出来事の学問。場所、人物、出来事、物体の意義を想起するのに使用します。
> * **法律：** 法実務の学問。提案された行動の合法性の判断、判例の検索、弁護などに使用します。

> * **哲学：** 存在の意味の学問。論理、実存主義など。信条の想起や議論に使用します。
> * **政治：** 統治システムの学問。パワーブロックの理解や政治的影響力の行使に使用します。
> * **地域/サブ：** 都市や国に関する一般情報。宿の探し方や地元の政治、商人の特定に使用します。
> * **宗教/サブ：** 神話や儀式の詳細。タブーの回避、教義の議論、異端の特定に使用します。
> * **ストリートワイズ：** 貧困層から犯罪裏社会までの知識。隠れ家探しや盗品の換金に使用します。

### 言語（各種）

**基本成功率：** INT×5 または 00%（後述）

**カテゴリー：** コミュニケーション

外国語を含む、言語による口頭コミュニケーション能力。他の言語は家庭、学校、教会、仕事場、ストリートで習得できます。キャラクターは開始時に自身の言語をINT×5で習得しています。バイリンガルになるには言語スキルにポイントを割く必要があります。日常会話は「自動」で成功しますが、翻訳などの困難な状況ではロールが必要です。読み書きには「読み書き」を使用します。ファンブルは壊滅的な誤解を、成功は円滑なコミュニケーションをもたらします。

**専門分野：** 言語ごと。それぞれ別のスキルとして成長させる必要があります。

**システムメモ：** EDUオプションルールを使用している場合は、INT×5とEDU×5の高い方を使用します。難解な方言や古代の言語は「困難」です。複雑な概念は複数回のロールが必要な場合があります。「流暢度」表を参照してください。

##### 流暢度

| スキルレーティング | 流暢度 |
| :---- | :---- |
| 01–05 | 数十単語程度。単純なアイデアのみ。複雑な交渉は不可。 |
| 06–25 | 生存に必要な単純な要求のみ可能。複雑なコミュニケーションは「困難」。 |
| 26–50 | 子供以上。ほとんどの意思疎通は可能。スキルは使えるが「困難」が残る。 |
| 51–75 | 物語や歌が可能。スラングやジョークも通じる。現地人として通せる。複雑なコミュニケーションはフルで可能。 |
| 76–00 | 詩人、哲学者レベル。現地の方言も真似られる。専門用語も容易。 |

### 聞き耳

**システムメモ：** アクティブにもパッシブにも使用されます。GMは秘密裏にロールを行うことを選ぶかもしれません。

### 読み書き（各種）

**カテゴリー：** メンタル

**専門分野：** 言語別。現代社会では言語スキルと常に等しいです。

**システムメモ：** 難解な方言や古代の筆記言語は「困難」です。本などの複雑な文書は複数ロールが必要になる場合があります。

### 武道

**基本成功率：** 01%

**カテゴリー：** 戦闘

特定の戦闘スタイルの習得。標的に最大限のダメージを与える特定の動きや打撃のために使用します。常に他のスキル（格闘、近接武器、遠隔武器、組付き）と組み合わせて使用されます。

**専門分野：** ボクシング、カポエイラ、エスクリマ、フェンシング、ジークンドー、空手、剣術、キックボクシング、カンフー、弓術など。GMは組み合わせ可能な戦闘スキルを制限できます。

**効果：** 武道は単独ではロールしません。メインスキルに対してロールし、武道スキルと比較します。
* **ファンブル：** 適したファンブル結果を使用。
* **失敗：** 出目が武道スキルを超えているが、メインスキル以下なら通常の攻撃成功。
* **成功：** 出目が武道とメインスキルの両方以下なら、基本ダメージを2倍ロールして合計する。ダメージボーナスは倍になりません。
* **スペシャル成功：** 上記と同様。スペシャル成功時の追加ダメージもロールします。
* **クリティカル成功：** 上記と同様。メインロールがクリティカルなら、装甲を無視し、追加の基本ダメージをロールします。

**システムメモ：** 一つの戦闘スキルと連動します。複数攻撃時は武道スキルを分配しなければなりません。非常に強力なため、習得制限を設けることが推奨されます。

### 医学

**基本成功率：** 05%

**カテゴリー：** メンタル

**効果：**
* **ファンブル：** 患者は1の一般ダメージを受けるか、能力値が1低下します。

* **成功：** 応急手当の効果に加え、以下のいずれか：

    * 毒・病気の継続ダメージ停止。
    * 毒・病気のキャラクターが安定し、週1D3-1のポイント回復。
* **スペシャル成功：** 2D3回復、または1D3能力値回復。
* **クリティカル成功：** 1D3+3 HP回復、または1D3+1能力値回復。

**システムメモ：** 各疾患につき1回のみ有効です。不衛生な環境は「困難」です。特殊設備は+20%のボーナス、未来技術は「易しい」にします。日常的な疾患は「自動」です。
