3. आप इस पूरी प्रक्रिया को git जाने बिना ब्राउज़र के माध्यम से कर सकते हैं। हालाँकि, github desktop सीखने से आप दुनिया के लिए लाइव करने से पहले किसी भी बदलाव का स्थानीय स्तर पर परीक्षण कर पाएंगे।

> यदि आपने कोई डोमेन नाम पंजीकृत किया है, तो आप इस प्रक्रिया के साथ उसका उपयोग करके मेरे जैसा SRD बना सकते हैं https://srd.7thextinctionrpg.com

8. सुनिश्चित करें कि आपके पास ".nojekyll" फ़ाइल है, यह एक खाली फ़ाइल है जिसकी आवश्यकता Github पर वेबसाइट होस्ट करते समय होती है, अन्यथा SRD ठीक से प्रदर्शित नहीं होगा। *(यह GitHub Pages को निर्देश देता है कि प्रकाशित फ़ाइलों को Jekyll के माध्यम से न चलाएँ)।*


## अपनी सामग्री जोड़ना

### *.md फ़ाइलें

.md फ़ाइलें मार्कडाउन फ़ाइलें हैं, मार्कडाउन एक हल्की मार्कअप भाषा है जिसका उपयोग आप सादे टेक्स्ट दस्तावेज़ों में स्वरूपण तत्व जोड़ने के लिए कर सकते हैं। अपनी सामग्री के आकार के आधार पर, आप या तो अपने गेम की सारी जानकारी एक ही *.md फ़ाइल में रख सकते हैं, या जैसा कि मैंने [7thextinctionrpg.com](https://srd.7thextinctionrpg.com) पर किया है, प्रत्येक अध्याय के लिए अलग फ़ाइलें बना सकते हैं। "sample.md" कुछ स्वरूपण उदाहरण प्रदान करता है।

मार्कडाउन भाषा सीखना बहुत आसान है, सिंटैक्स की पूरी सूची के लिए पूर्वपेक्षाएँ के अंतर्गत बिंदु 2 पर दिए गए लिंक का उपयोग करें।

### _Sidebar.md

यह आपका मेनू है, वेबसाइट के बाईं ओर नेविगेशन फलक। एक बार जब आप अपनी रिपॉजिटरी में कोई मार्कडाउन फ़ाइल जोड़ लेते हैं, तो आपको फ़ाइल को यहाँ जोड़ना होगा ताकि इसकी सामग्री शामिल हो सके। मौजूदा स्वरूपण का पालन करें।


## रिपॉजिटरी को वेबसाइट में बदलने के लिए Github Pages सक्षम करें

1. अपनी रिपॉजिटरी में 'Settings' पर क्लिक करें

![Website-Step1](/_media/Website-Step1.png)

2. बाईं ओर के मेनू पर 'Pages' चुनें

![Website-Step2](/_media/Website-Step2.png)

3. यदि आपने रिपॉजिटरी को 'public' नहीं बनाया है, तो आपके पास दो विकल्प हैं
    a. रिपॉजिटरी को सार्वजनिक करें, जो आपको अपने SRD वेबसाइट को मुफ्त में होस्ट करने के लिए Github pages का उपयोग करने की अनुमति देगा
    b. अपने Github खाते को अपग्रेड करें (इसे लिखते समय इसकी लागत $4 प्रति माह या $48 वार्षिक शुल्क है)

4. 'Branch' के अंतर्गत 'main' चुनें और save पर क्लिक करें

5. इसे 10-20 सेकंड दें फिर पेज को रिफ्रेश करें

6. अब आप अपना URL देख पाएंगे जैसे https://coweater.github.io/mysrd/

![Website-Step6](/_media/Website-Step6.png)

## अपने SRD में निःशुल्क आइकन प्रदर्शित करने के लिए Fontawesome और/या Material Icons प्लगइन का उपयोग करना

### Fontawesome

निःशुल्क आइकन और एनिमेटेड आइकन प्राप्त करने के लिए Fontawesome का उपयोग करें। सब्सक्राइब किए गए उपयोगकर्ता प्रो आइकन का उपयोग कर सकते हैं

1. [Fontawesome](https://fontawesome.com/icons) पर आइकन ढूँढें
2. आइकन चुनें
3. पॉपअप विंडो में, HTML टैब के अंतर्गत " " के बीच सब कुछ कॉपी करें

```EXAMPLE
<i वर्ग="fa-solid fa-dice-d20"></i>
```

4. कॉपी किए गए टेक्स्ट को `:` के बीच रखें, कोई स्पेस न छोड़ें

```EXAMPLE
fa-solid fa-dice-d20
```

### Material Icons

अधिक निःशुल्क आइकन के लिए Material Icons का उपयोग करें

1. [Material Icons](https://fonts.google.com/icons) पर आइकन ढूँढें
2. वेब स्पैन लिंक को सीधे अपनी मार्कडाउन फ़ाइलों में कॉपी और इन्सर्ट करें

```markup
<span वर्ग="material-icons">face</span>
```
