# ބޭސިކް ރޯލްޕްލޭއިންގ ޔުނިވަރސަލް ގޭމް އިންޖީން

އޯ.އާރު.ސީ (ORC) ކޮންޓެންޓް ޑޮކިއުމަންޓް

## ކްރެޑިޓްސް

މިއީ ސްޓީވް ޕެރިން، ސްޓީވް ހެންޑަރސަން، ވޯރެން ޖޭމްސް، ގްރެގް ސްޓެފޯޑް، ސޭންޑީ ޕީޓަރސަން، ރޭ ޓަރނީ، އަދި ލިން ވިލިސް އުފެއްދި ބޭސިކް ރޯލްޕްލޭއިންގ ނިޒާމުގެ މައްޗަށް ބިނާކޮށް ހަދާފައިވާ އެއްޗެކެވެ.

**ލިޔުންތެރިން:** ޖޭސަން ޑިއުރަލް އަދި ސްޓީވް ޕެރިން

**ޕްރޮޑިއުސަރ:** ނީލް ރޮބިންսަން

**އިތުރު ކްރެޑިޓްސް:** ޑާރިއާ ޕިލާރޗިކް، ރިކް މެއިންޓްސް، މައިކަލް އޯ ބްރަޔަން، އަދި ޖެފް ރިޗަރޑް

**ޚާއްޞަ ޝުކުރު:** ކެން ސެއިންޓް އަންޑްރޭ، ކެން އޮސްޓިން، ވިލިއަމް ބާރޓަން، ބިލް ޑަން، ކެން ފިންލޭސަން، މާކް އެލް. ގޭމްބްލަރ، ސޭމް ޖޯންސަން، ވިލިއަމް ޖޯންސް، ރޮޑްނީ ލިއަރީ، ބެން މޮންރޯ، ގޯޑަން މޮންސަން، ސާރާ ނިއުޓަން، ސޭމް ޝަރލީ، މާކް މޮރިސަން، އަދި ރިޗަރޑް ވަޓްސް
