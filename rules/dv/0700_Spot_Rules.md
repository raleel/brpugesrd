# 7. ސްޕޮޓް ރޫލްސް (Spot Rules)

ހަނގުރާމައިގެ ތެރޭގައި، އެކްޝަން ސީކުއެންސްތަކުގައި، ނުވަތަ ޚާއްޞަ ޙާލަތްތަކުގައި އެކި ކަހަލަ ތަފާތު ޙާލަތްތައް ކުރިމަތިވެދާނެއެވެ. މި ‘ސްޕޮޓް ރޫލްސް’ އަކީ ގޭމް މާސްޓަރުގެ ބޭނުމަށްޓަކައި އެކުލަވާލެވިފައިވާ ޤަވާއިދުތަކެކެވެ. ކުޅުންތެރިއެއްގެ ހައިސިއްޔަތުން މި ޤަވާއިދުތައް އެނގުން ލާޒިމު ނޫނަސް، ކޮންމެވެސް ވަރަކަށް އެނގިފައި ހުރުމަކީ ބޭނުންތެރި ކަމެކެވެ.

## މި ބައިގައި ހިމެނޭ ސްޕޮޓް ރޫލްސް

| އެސިޑް (Acid) | ހަނގުރާމައިން ދުރަށް ދިއުން (Disengaging) | ބަންޑުން އޮތުން (Prone) |
| :--- | :--- | :--- |
| ވައިގެ ހަނގުރާމަ (Aerial Combat) | ހަތިޔާރު ނެގުން ނުވަތަ ބަދަލުކުރުން | ހަމަލާގެ ބާރު ކުޑަކުރުން (Pulling Blows) |
| އަމާޒުކޮށްގެން ހަމަލާދިނުން (Aimed Attacks) | އެތެރޭގެ މާހައުލު (Enclosed Environments) | ކުއްލިއަކަށް ހަތިޔާރު ނެގުން (Quickdraws) |
| ކުއްލި ހަމަލާ (Ambushes) | ބަނދެގަތުން (Entangle) | ރޭޑިއޭޝަން (Radiation) |
| ސަރަޙައްދީ ހަމަލާ (Area Attacks) | ގޮވުންތައް (Explosions) | ޝީލްޑް އަދި މިސައިލް ހަމަލާ |
| ހަތިޔާރު ހަލާކުވުން (Armor Damaged) | ދުރު ރާސްތާ (Extended Range) | މައްޗަށް ނުވަތަ ތިރިއަށް ބަޑިޖެހުން |
| އަޢުރާ ހަމަލާ (Aura Attacks) | ވެއްޓުން (Falling) | އޮމާން ނުވަތަ ހަމަ ނޫން ސަރަޙައްދު |
| އޮޓޯފައިއަރ (Autofire) | ވެއްޓިފައި ހުއްޓައި ހަނގުރާމަކުރުން | ހޭނެތުން ނުވަތަ ހަމަލާ ކޮންޓްރޯލްކުރުން |
| ފަހަތުން ހަމަލާދިނުން | އަލިފާން އަދި ހޫނު (Fire and Heat) | މަތީ/ދަށު މަޤާމު (Superior/Inferior) |
| ބޮޑެތި އަދި ކުދި އަމާޒުތައް | ހަނގުރާމައިގެ ތެރެއަށް ބަޑިޖެހުން | ގިނަ މީހުންނާ ހަނގުރާމަކުރުން |
| ދެ ފަރާތް ވެސް ސިއްސައިގެން ދިއުން | ފޯޓިފައިޑް މަޤާމުތައް (Fortified Positions) | ސުވީޕް އެޓޭކް (Sweep Attacks) |
| ހަލާކުވެފައިވާ ހަތިޔާރު | ހަތިޔާރަކަށް ބޭނުންކުރެވޭ ތަކެތި | އުކާ ހަތިޔާރު (Thrown Weapons) |
| ޗޭސް (Chases) | އަމިއްލައަށް ހަދާ ހަތިޔާރު | ދެ ހަތިޔާރު ބޭނުންކުރުން |

| ކައިރި ހަނގުރާމަ (Close Combat) | ހޭނައްތާލާ ހަމަލާ (Knockout Attacks) | ވެކިއުމް (Vacuum) |
| ކައިރިވުން (Closing) | އަލިކަން (Light Sources) | ވޮލީ ފަޔަރ (Volley Fire) |

| އަނދިރިކަން (Darkness) | ސަވާރީގައި ހަނގުރާމަކުރުން | ޒީރޯ-ގްރެވިޓީ ހަނގުރާމަ |

## އެސިޑް (Acid)

އެސިޑް ނުވަތަ ދަބަރު ޖައްސާ މާއްދާތަކާ ކުރިމަތިވުމަކީ ނުރައްކަލެކެވެ. ހުރިހާ އެސިޑެއް ވެސް އެއްގޮތަކަށް ބަލާށެވެ. އެސިޑްގެ ގެއްލުމުގެ މިންވަރަކީ އެއީ ކިހާ ބާރުގަދަ އެސިޑެއްކަން ދައްކުވައިދޭ އެއްޗެކެވެ. ހަމައެކަނި ބޮޑުކޮށް ގުޅުން އުފެދޭ ހާލަތްތަކުގައި (އަތް ނުވަތަ ފައި އެސިޑްގެ ތެރެއަށް ލުން ނުވަތަ ލޮލަށް އެސިޑް އެރުން ފަދަ) ނޫނީ ސީރިއަސް އަދި ވަގުތީ ގެއްލުން ނުލިބޭނެއެވެ.

* ބަލިކަށި އެސިޑުން ކޮންމެ ރައުންޑަކަށް 1D3–1 ޕޮއިންޓުގެ ގެއްލުން ލިބޭނެއެވެ.

* ވަރުގަދަ އެސިޑުން ކޮންމެ ރައުންޑަކަށް 1D4 ޕޮއިންޓުގެ ގެއްލުން ލިބޭނެއެވެ.

* ވަރަށް ވަރުގަދަ އެސިޑުން ކޮންމެ ރައުންޑަކަށް 1D6+1 ޕޮއިންޓުގެ ގެއްލުން ލިބޭނެއެވެ.

ހެދުން (Armor) އެޅުމުން އެސިޑްގެ އަސަރު މުޅިން ނުކެނޑުނަސް، ވަގުތީ ގޮތުން އޭގެ ގެއްލުން ކުޑަކުރެއެވެ. ئەگەر އަމާޒަކީ ހެދުން އަޅާފައިވާ މީހެއްނަމަ، ލިބޭ ގެއްލުން ދެބައިކުޅަ އެއްބަޔަށް ކުޑަކުރާށެވެ (މައްޗަށް ރައުންޑްކުރޭ). ނަމަވެސް ގޭމް މާސްޓަރު ހެދުމުގެ ބާވަތަށް ބަލައި މިއަށް ބަދަލު ގެނެވިދާނެއެވެ. އެސިޑްގެ ގެއްލުމުން ހެދުން ރައްކާތެރިކޮށްދޭ މުއްދަތަކީ 1D3 ރައުންޑެވެ. އެ މުއްދަތު ހަމަވުމުން، އެސިޑުން އާދައިގެ ގެއްލުން ލިބޭނެއެވެ.

ވަރަށް ބާރުގަދަ އެސިޑް ޖެހުމުން ހެދުމުގެ ބައިތައް ވިރިގެން ދެއެވެ: 1D6 ރައުންޑަށް ފަހު އެ ހެދުމަކީ ބޭނުން ނުހިފޭ އެއްޗަކަށް ވެގެންދެއެވެ. މިއީ 1D3 ރައުންޑުގެ ރައްކާތެރިކަން ލިބޭ މުއްދަތުގެ ތެރޭގައި ވެސް ހިނގާ ކަމެކެވެ.

ގޭމް މާސްޓަރުގެ ނިންމުމަށް، މުޤައްދަސް ފެން (Holy water) ފަދަ ތަކެތި ވެމްޕަޔަރުން ނުވަތަ ޖިންނި ފަދަ ނުބައި މަޚުލޫޤުންނާ ދެކޮޅަށް އެސިޑް ފަދައިން މަސައްކަތް ކޮށްފާނެއެވެ.

---

*(ނޯޓް: މިއީ ތަރުޖަމާގެ ފެށުމެވެ. އެހެން ބައިތައް ވެސް މި އުސޫލުން ތަރުޖަމާ ކުރެވޭނެއެވެ.)*
