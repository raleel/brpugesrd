# محرك الألعاب العالمي للعب الأدوار الأساسي (Basic Roleplaying)

وثيقة محتوى ORC

## فريق العمل

استناداً إلى نظام اللعب بالأدوار الأساسي (Basic Roleplaying) الذي ابتكره ستيف بيرين، وستيف هندرسون، ووارن جيمس، وجريج ستافورد، وساندي بيترسن، وراي تورني، ولين ويليس.

**المؤلفون:** جيسون دورال وستيف بيرين

**المنتج:** نيل روبنسون

**إضافات فريق العمل:** داريا بيلارزيك، وريك مينتس، ومايكل أوبراين، وجيف ريتشارد

**شكر خاص:** كين سانت أندري، وكين أوستن، وويليام بارتون، وبيل دان، وكين فينلايسون، ومارك إل. جامبلر، وسام جونسون، وويليام جونز، ورودني ليري، وبن مونرو، وجوردون مونسون، وسارة نيوتن، وسام شيرلي، ومارك موريسون، وريتشارد واتس.
