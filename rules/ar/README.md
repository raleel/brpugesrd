# محرك ألعاب تمثيل الأدوار الأساسي (Basic Roleplaying)

مستند محتوى ORC

## الاعتمادات

يستند هذا العمل إلى نظام تمثيل الأدوار الأساسي (Basic Roleplaying) الذي ابتكره كل من: ستيف بيرين، ستيف هندرسون، وارن جيمس، جريج ستافورد، ساندي بيترسن، راي تورني، ولين ويليس.

**المؤلفون:** جيسون دورال وستيف بيرين

**المنتج:** نيل روبنسون

**اعتمادات إضافية:** داريا بيلارزيك، ريك مينتس، مايكل أوبراين، وجيف ريتشارد.

**شكر خاص:** كين سانت أندري، كين أوستن، ويليام بارتون، بيل دان، كين فينلايسون، مارك إل. جامبلر، سام جونسون، ويليام جونز، رودني ليري، بن مونرو، جوردون مونسون، سارة نيوتن، سام شيرلي، مارك موريسون، وريتشارد واتس.
