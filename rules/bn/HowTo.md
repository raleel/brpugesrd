# পূর্বশর্ত (Prerequisites)

১. [মার্কডাউন ল্যাঙ্গুয়েজ](https://www.markdownguide.org/basic-syntax/) সম্পর্কে প্রাথমিক ধারণা।

২. আপনার যদি কোনো [গিটহাব (github)](https://github.com/) অ্যাকাউন্ট না থাকে, তবে একটি বিনামূল্যে অ্যাকাউন্ট তৈরি করতে হবে। আপনার আরপিজি (RPG)-এর নামে অ্যাকাউন্ট তৈরি করার পরামর্শ দিচ্ছি, কারণ এটি সেই ইউআরএল (URL)-এর অংশ হয়ে যাবে যা ব্যবহার করে মানুষ আপনার এসআরডি (SRD) অ্যাক্সেস করবে। 

৩. আপনি গিট (git) না জেনেই ব্রাউজারের মাধ্যমে পুরো প্রক্রিয়াটি সম্পন্ন করতে পারবেন। তবে গিটহাব ডেস্কটপ শিখলে আপনি সরাসরি লাইভ করার আগে স্থানীয়ভাবে যেকোনো পরিবর্তন পরীক্ষা করে দেখতে পারবেন।

> যদি আপনার কোনো ডোমেইন নাম নিবন্ধিত থাকে, তবে আপনি এই প্রক্রিয়ার মাধ্যমে আমার মতো একটি এসআরডি তৈরি করতে পারেন: https://srd.7thextinctionrpg.com

## আপনার কন্টেন্ট যোগ করা

### *.md ফাইল

.md ফাইলগুলো হলো মার্কডাউন ফাইল। মার্কডাউন হলো একটি হালকা মার্কআপ ল্যাঙ্গুয়েজ যা আপনি সাধারণ টেক্সট ডকুমেন্টে ফরম্যাটিং উপাদান যোগ করতে ব্যবহার করতে পারেন। আপনার কন্টেন্টের আকারের ওপর ভিত্তি করে আপনি আপনার গেমের সমস্ত তথ্য একটি সিঙ্গেল *.md ফাইলে রাখতে পারেন, অথবা [7thextinctionrpg.com](https://srd.7thextinctionrpg.com)-এর মতো প্রতিটি অধ্যায়ের জন্য আলাদা ফাইল তৈরি করতে পারেন। "sample.md"-এ কিছু ফরম্যাটিং উদাহরণ দেওয়া আছে। 

মার্কডাউন ল্যাঙ্গুয়েজ শেখা খুব সহজ, সিনট্যাক্সের সম্পূর্ণ তালিকার জন্য উপরের পূর্বশর্তের ২ নম্বর পয়েন্টে দেওয়া লিঙ্কটি ব্যবহার করুন। 

### _Sidebar.md

এটি হলো ওয়েবসাইটের বাম পাশের মেনু বা নেভিগেশন প্যান। আপনি যখন আপনার রিপোজিটরিতে কোনো মার্কডাউন ফাইল যোগ করবেন, তখন এর বিষয়বস্তু অন্তর্ভুক্ত করার জন্য এখানে ফাইলটি যোগ করতে হবে। বিদ্যমান ফরম্যাটিং অনুসরণ করুন।

## আপনার এসআরডিতে বিনামূল্যে আইকন প্রদর্শনের জন্য ফন্টঅসাম (Fontawesome) এবং/অথবা ম্যাটেরিয়াল আইকন (Material Icons) প্লাগইন ব্যবহার করা

### ফন্টঅসাম (Fontawesome)

বিনামূল্যে আইকন এবং অ্যানিমেটেড আইকন পেতে ফন্টঅসাম ব্যবহার করুন। সাবস্ক্রাইব করা ব্যবহারকারীরা প্রো আইকন ব্যবহার করতে পারবেন।

১. [Fontawesome](https://fontawesome.com/icons)-এ আইকনটি খুঁজুন।
২. আইকনটি নির্বাচন করুন।
৩. পপআপ উইন্ডোতে, HTML ট্যাবের নিচে " " এর মধ্যবর্তী সবকিছু কপি করুন।

```EXAMPLE
<i class="fa-solid fa-dice-d20"></i>
```

৪. কপি করা টেক্সটটি `:` -এর মাঝে রাখুন (কোনো স্পেস দেবেন না)।

```EXAMPLE
fa-solid fa-dice-d20
```

### ম্যাটেরিয়াল আইকন (Material Icons)

আরও বিনামূল্যে আইকন পেতে ম্যাটেরিয়াল আইকন ব্যবহার করুন।

১. [Material Icons](https://fonts.google.com/icons)-এ আইকনগুলো খুঁজুন।
২. ওয়েব স্প্যান লিঙ্কটি কপি করুন এবং সরাসরি আপনার মার্কডাউন ফাইলে ইনসার্ট করুন।

```markup
<span class="material-icons">face</span>
```
