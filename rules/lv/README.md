# Basic Roleplaying Universal Game Engine

ORC satura dokuments

## Kredīti

Pamatojoties uz Basic Roleplaying sistēmu, kuru izveidojuši Stīvs Perins (Steve Perrin), Stīvs Hendersons (Steve Henderson), Vorens Džeimss (Warren James), Gregs Stafords (Greg Stafford), Sendijs Pētersens (Sandy Petersen), Rejs Tērnejs (Ray Turney), Lins Viliss (Lynn Willis).

**Autori:** Džeisons Durals (Jason Durall) un Stīvs Perins (Steve Perrin)

**Producents:** Nīls Robinsons (Neil Robinson)

**Papildu kredīti:** Darija Pilarčika (Daria Pilarczyk), Riks Meintss (Rick Meints), Maikls O’Braiens (Michael O’Brien) un Džefs Ričards (Jeff Richard)

**Īpaša pateicība:** Kenam Sentendrē (Ken St. Andre), Kenam Ostinam (Ken Austin), Viljamam Bārtonam (William Barton), Bilam Danam (Bill Dunn), Kenam Finlejsonam (Ken Finlayson), Markam L. Gambleram (Mark L. Gambler), Semam Džonsonam (Sam Johnson), Viljamam Džounsam (William Jones), Rodnijam Līrijam (Rodney Leary), Benam Monro (Ben Monroe), Gordonam Monsonam (Gordon Monson), Sārai Ņūtonei (Sarah Newton), Semam Šērlijam (Sam Shirley), Markam Morisonam (Mark Morrison) un Ričardam Votsam (Richard Watts)
