# Προαπαιτούμενα

1. Μια βασική κατανόηση της [γλώσσας markdown](https://www.markdownguide.org/basic-syntax/).

2. Θα χρειαστεί να δημιουργήσετε έναν δωρεάν [github](https://github.com/) λογαριασμό αν δεν έχετε ήδη. Προτείνεται να χρησιμοποιήσετε το όνομα του RPG σας, καθώς αυτό θα γίνει μέρος του URL που θα χρησιμοποιούν οι χρήστες για να έχουν πρόσβαση στο SRD σας.

3. Μπορείτε να ολοκληρώσετε όλη τη διαδικασία μέσω του περιηγητή (browser) χωρίς να γνωρίζετε git. Ωστόσο, η εκμάθηση του github desktop θα σας επιτρέψει να δοκιμάζετε τυχόν αλλαγές τοπικά πριν τις δημοσιεύσετε για να τις δει ο κόσμος.

> Αν έχετε κατοχυρωμένο όνομα τομέα (domain name), μπορείτε να το χρησιμοποιήσετε σε αυτή τη διαδικασία για να δημιουργήσετε ένα SRD όπως έχω κάνει εγώ στη διεύθυνση https://srd.7thextinctionrpg.com

# Η Διαδικασία

## Δημιουργία του Αποθετηρίου (Repository) στο Github

1. Συνδεθείτε στο Github

2. Πλοηγηθείτε στο δημόσιο πρότυπο https://github.com/7thExtinctionrpg/RPG_SRD_Template

3. Κάντε κλικ στο "Use this template"

![Step3](/_media/Step3.png)

4. Επιλέξτε "Create a new repository"

5. Εισάγετε ένα όνομα αποθετηρίου

![Step5](/_media/Step5.png)

6. Επιλέξτε 'Private'

7. Επιλέξτε 'Create repository'

Θα χρειαστούν 5-30 δευτερόλεπτα για να αντιγραφεί το πρότυπο, και στη συνέχεια θα έχετε το δικό σας αντίγραφο.

8. Βεβαιωθείτε ότι έχετε το αρχείο ".nojekyll". Πρόκειται για ένα κενό αρχείο που απαιτείται κατά τη φιλοξενία μιας ιστοσελίδας στο Github, διαφορετικά το SRD δεν θα εμφανίζεται σωστά. *(Λέει στο GitHub Pages να μην επεξεργαστεί τα δημοσιευμένα αρχεία μέσω του Jekyll).*


## Προσθήκη του Περιεχομένου σας

### Αρχεία *.md

Τα αρχεία .md είναι αρχεία markdown. Το Markdown είναι μια ελαφριά γλώσσα σήμανσης που μπορείτε να χρησιμοποιήσετε για να προσθέσετε στοιχεία μορφοποίησης σε έγγραφα απλού κειμένου. Ανάλογα με το μέγεθος του περιεχομένου σας, μπορείτε είτε να τοποθετήσετε όλες τις πληροφορίες του παιχνιδιού σας σε ένα ενιαίο αρχείο *.md, είτε, όπως έχω κάνει εγώ στο [7thextinctionrpg.com](https://srd.7thextinctionrpg.com), να δημιουργήσετε ξεχωριστά αρχεία για κάθε κεφάλαιο. Το "sample.md" παρέχει ορισμένα παραδείγματα μορφοποίησης.

Η γλώσσα Markdown είναι πολύ εύκολη στην εκμάθηση. Χρησιμοποιήστε τον σύνδεσμο που παρέχεται στο σημείο 2 των Προαπαιτούμενων παραπάνω για μια πλήρη λίστα της σύνταξης.

### _Sidebar.md

Αυτό είναι το μενού σας, το πλαίσιο πλοήγησης στην αριστερή πλευρά της ιστοσελίδας. Μόλις προσθέσετε ένα αρχείο markdown στο αποθετήριό σας, πρέπει να προσθέσετε το αρχείο εδώ ώστε να συμπεριληφθούν τα περιεχόμενά του. Ακολουθήστε την υπάρχουσα μορφοποίηση.


## Ενεργοποίηση του Github Pages για τη μετατροπή του Αποθετηρίου σε Ιστοσελίδα

1. Στο αποθετήριό σας, κάντε κλικ στο 'Settings'

![Website-Step1](/_media/Website-Step1.png)

2. Επιλέξτε 'Pages' από το μενού στην αριστερή πλευρά

![Website-Step2](/_media/Website-Step2.png)

3. Αν δεν έχετε κάνει το αποθετήριο 'public', έχετε δύο επιλογές:
    a. Κάντε το αποθετήριο δημόσιο, το οποίο θα σας επιτρέψει να χρησιμοποιήσετε το Github pages για να φιλοξενήσετε δωρεάν την ιστοσελίδα του SRD σας.
    b. Αναβαθμίστε τον λογαριασμό σας στο Github (τη στιγμή που γράφεται αυτό, το κόστος είναι 4$ το μήνα ή 48$ ετησίως).

4. Στο 'Branch' επιλέξτε 'main' και κάντε κλικ στο save.

5. Περιμένετε 10-20 δευτερόλεπτα και μετά ανανεώστε τη σελίδα.

6. Θα δείτε πλέον το URL σας, όπως https://coweater.github.io/mysrd/

![Website-Step6](/_media/Website-Step6.png)

## Χρήση προσθέτων Fontawesome ή/και Material Icons για την εμφάνιση δωρεάν εικονιδίων στο SRD σας

### Fontawesome

Χρησιμοποιήστε το Fontawesome για να αποκτήσετε δωρεάν εικονίδια και κινούμενα εικονίδια. Οι εγγεγραμμένοι χρήστες μπορούν να χρησιμοποιήσουν τα Pro Icons.

1. Βρείτε το εικονίδιο στο [Fontawesome](https://fontawesome.com/icons)
2. Επιλέξτε το εικονίδιο
3. Στο αναδυόμενο παράθυρο, κάτω από την καρτέλα HTML αντιγράψτε τα πάντα ανάμεσα σε " "

```EXAMPLE
<i class="fa-solid fa-dice-d20"></i>
```

4. Τοποθετήστε το κείμενο που αντιγράψατε ανάμεσα σε `:` χωρίς κενά

```EXAMPLE
fa-solid fa-dice-d20
```

### Material Icons

Χρησιμοποιήστε το Material Icons για περισσότερα δωρεάν εικονίδια

1. Βρείτε τα εικονίδια στο [Material Icons](https://fonts.google.com/icons)
2. Αντιγράψτε & εισάγετε τον σύνδεσμο span του ιστού απευθείας στα αρχεία markdown σας

```markup
<span class="material-icons">face</span>
```
