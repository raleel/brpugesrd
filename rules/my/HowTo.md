# ကြိုတင်လိုအပ်ချက်များ

၁။ [markdown language](https://www.markdownguide.org/basic-syntax/) အကြောင်း အခြေခံ နားလည်မှု။

၂။ အကယ်၍ သင့်တွင် [github](https://github.com/) အကောင့် မရှိသေးပါက အခမဲ့ အကောင့်တစ်ခု ပြုလုပ်ရန် လိုအပ်ပါသည်။ သင်၏ RPG အမည်ကို အသုံးပြုရန် အကြံပြုလိုပါသည်၊ အဘယ်ကြောင့်ဆိုသော် ၎င်းသည် လူများ သင်၏ SRD ကို အသုံးပြုမည့် URL ၏ အစိတ်အပိုင်းတစ်ခု ဖြစ်လာမည်ဖြစ်သောကြောင့် ဖြစ်သည်။

၃။ Git ကို မသိဘဲ ဘရောက်ဆာမှတစ်ဆင့် ဤလုပ်ငန်းစဉ်တစ်ခုလုံးကို သင် လုပ်ဆောင်နိုင်ပါသည်။ သို့သော် github desktop ကို သင်ယူခြင်းက အများပြည်သူအတွက် မထုတ်ပြန်မီ သင်၏ အပြောင်းအလဲများကို ဒေသအလိုက် စမ်းသပ်နိုင်စေမည်ဖြစ်သည်။

> အကယ်၍ သင့်တွင် ဒိုမိန်းအမည်တစ်ခု မှတ်ပုံတင်ထားပါက၊ ဤလုပ်ငန်းစဉ်ဖြင့် ကျွန်ုပ်ပြုလုပ်ထားသည့် https://srd.7thextinctionrpg.com ကဲ့သို့ SRD တစ်ခုကို ဖန်တီးနိုင်ပါသည်။

## သင်၏ အကြောင်းအရာများ ထည့်သွင်းခြင်း

### *.md ဖိုင်များ

.md ဖိုင်များသည် markdown ဖိုင်များဖြစ်သည်။ Markdown ဆိုသည်မှာ ရိုးရိုးစာသားစာရွက်စာတမ်းများတွင် ဖော်မတ်ချခြင်းဆိုင်ရာ အစိတ်အပိုင်းများကို ထည့်သွင်းရန် သင်အသုံးပြုနိုင်သော ပေါ့ပါးသည့် markup ဘာသာစကားတစ်ခုဖြစ်သည်။ သင်၏ အကြောင်းအရာ အရွယ်အစားပေါ်မူတည်၍ သင်၏ ဂိမ်းအချက်အလက်အားလုံးကို *.md ဖိုင်တစ်ခုတည်းတွင် ထည့်သွင်းနိုင်သည်၊ သို့မဟုတ် [7thextinctionrpg.com](https://srd.7thextinctionrpg.com) တွင် ကျွန်ုပ်ပြုလုပ်ထားသကဲ့သို့ အခန်းတစ်ခုစီအတွက် သီးခြားဖိုင်များ ခွဲ၍ ဖန်တီးနိုင်သည်။ "sample.md" တွင် ဖော်မတ်ချခြင်းဆိုင်ရာ နမူနာအချို့ ပါဝင်ပါသည်။

Markdown ဘာသာစကားသည် သင်ယူရန် အလွန်လွယ်ကူပါသည်။ အထက်ပါ ကြိုတင်လိုအပ်ချက်များ၏ အချက် ၂ တွင် ပေးထားသော လင့်ခ်ကို အသုံးပြု၍ Syntax များအားလုံးကို ကြည့်ရှုပါ။

### _Sidebar.md

၎င်းသည် ဝဘ်ဆိုက်၏ ဘယ်ဘက်ခြမ်းတွင်ရှိသော သင်၏ မီနူးနှင့် လမ်းညွှန်ချက်ပြား ဖြစ်သည်။ သင်၏ repository သို့ markdown ဖိုင်တစ်ခု ထည့်ပြီးသည်နှင့်၊ ၎င်း၏ အကြောင်းအရာများ ပါဝင်လာစေရန်အတွက် ဤနေရာတွင် ထိုဖိုင်ကို ထည့်သွင်းရန် လိုအပ်ပါသည်။ လက်ရှိ ဖော်မတ်ချပုံအတိုင်း လိုက်နာဆောင်ရွက်ပါ။

## ဖောင့်များ ပြောင်းလဲခြင်း

၁။ /_assets/style.css ဖိုင်ကို တည်းဖြတ်ပါ

၂။ 'body section' အောက်တွင် siteFont နှင့် headingFont ကို သင်တွေ့ရှိပါမည်

၃။ ၎င်းတို့ကို သင်အသုံးပြုလိုသော ဖောင့်များဖြင့် ပြောင်းလဲပါ

## သင်၏ SRD တွင် အခမဲ့ အိုင်ကွန်များ ပြသရန် Fontawesome နှင့်/သို့မဟုတ် Material Icons plugin ကို အသုံးပြုခြင်း

### Fontawesome

အခမဲ့ အိုင်ကွန်များနှင့် လှုပ်ရှားနေသော အိုင်ကွန်များ ရရှိရန် Fontawesome ကို အသုံးပြုပါ။ အသုံးပြုသူများသည် Pro Icons များကို အသုံးပြုနိုင်ပါသည်။

၁။ [Fontawesome](https://fontawesome.com/icons) တွင် အိုင်ကွန်ကို ရှာပါ
၂။ အိုင်ကွန်ကို ရွေးချယ်ပါ
၃။ ပေါ်လာသော window တွင် HTML tab အောက်ရှိ " " ကြားမှ အားလုံးကို ကူးယူပါ

```EXAMPLE
<i class="fa-solid fa-dice-d20"></i>
```

၄။ ကူးယူထားသော စာသားကို `:` ကြားတွင် နေရာလွတ်မထားဘဲ ထည့်သွင်းပါ

```EXAMPLE
fa-solid fa-dice-d20
```

### Material Icons

ပိုမိုများပြားသော အခမဲ့ အိုင်ကွန်များအတွက် Material Icons ကို အသုံးပြုပါ

၁။ [Material Icons](https://fonts.google.com/icons) တွင် အိုင်ကွန်များကို ရှာပါ
၂။ ဝဘ် span လင့်ခ်ကို ကူးယူပြီး သင်၏ markdown ဖိုင်များထဲသို့ တိုက်ရိုက် ထည့်သွင်းပါ

```markup
<span class="material-icons">face</span>
```
