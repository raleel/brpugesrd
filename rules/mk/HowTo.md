# Предуслови

1. Основно познавање на [markdown јазикот](https://www.markdownguide.org/basic-syntax/).

2. Ќе треба да креирате бесплатна [github](https://github.com/) сметка доколку ја немате. Ви препорачуваме да го користите името на вашата RPG игра бидејќи тоа ќе стане дел од URL-адресата што луѓето ќе ја користат за пристап до вашиот SRD. 

3. Целиот процес можете да го направите преку прелистувачот без да го познавате git. Сепак, учењето на GitHub Desktop ќе ви овозможи да ги тестирате сите промени локално пред да ги објавите во живо за светот да ги види.

> Ако имате регистрирано име на домен, можете да го користите со овој процес за да креирате SRD како што направив јас https://srd.7thextinctionrpg.com

# Процесот

## Креирање на складиште (Repository) на Github

1. Најавете се на Github

2. Одете до јавниот шаблон https://github.com/7thExtinctionrpg/RPG_SRD_Template

3. Кликнете на „Use this template“

![Step3](/_media/Step3.png)

4. Изберете „Create a new repository“

5. Внесете име на складиштето

![Step5](/_media/Step5.png)

6. Изберете „Private“ 

7. Изберете „Create repository“

Ќе бидат потребни 5-30 секунди за копирање на шаблонот, потоа ќе ја имате вашата сопствена копија.

8. Осигурете се дека ја имате датотеката „.nojekyll“. Ова е празна датотека која е потребна при хостирање на веб-страница на Github, во спротивно SRD нема да се прикажува правилно. *(Му кажува на GitHub Pages да не ги обработува објавените датотеки преку Jekyll).*


## Додавање на вашата содржина

### *.md датотеки

.md датотеките се markdown датотеки. Markdown е лесен јазик за означување што можете да го користите за додавање елементи за форматирање во текстуални документи. Во зависност од големината на вашата содржина, можете или да ги ставите сите информации за вашата игра во една *.md датотека, или како што направив јас на [7thextinctionrpg.com](https://srd.7thextinctionrpg.com), да креирате посебни датотеки за секое поглавје. „sample.md“ дава неколку примери за форматирање. 

Markdown јазикот е многу лесен за учење, користете ја врската дадена во точка 2 под Предуслови погоре за целосна листа на синтакса. 

### _Sidebar.md

Ова е вашето мени, навигациско панелче на левата страна од веб-страницата. Откако ќе додадете markdown датотека во вашето складиште, треба да ја додадете датотеката овде за нејзината содржина да биде вклучена. Следете го постоечкото форматирање.


## Овозможување на Github Pages за претворање на складиштето во веб-страница

1. Во вашето складиште кликнете на „Settings“

![Website-Step1](/_media/Website-Step1.png)

2. Изберете „Pages“ од менито на левата страна

![Website-Step2](/_media/Website-Step2.png)

3. Ако сè уште не сте го направиле складиштето „public“, имате два избора:
    a. Направете го складиштето јавно, што ќе ви овозможи да го користите Github Pages за бесплатно хостирање на вашата SRD веб-страница
    b. Надградете ја вашата Github сметка (во моментот на пишување, ова чини 4 долари месечно или 48 долари годишна претплата)

4. Под „Branch“ изберете „main“ и кликнете save

5. Почекајте 10-20 секунди, а потоа освежете ја страницата

6. Сега ќе ја видите вашата URL-адреса, на пример https://coweater.github.io/mysrd/

![Website-Step6](/_media/Website-Step6.png)


## Промена на фонтови

1. Уредете ја датотеката /_assets/style.css

2. Под секцијата „body“ ќе ги најдете siteFont и headingFont

3. Променете ги овие со фонтовите што сакате да ги користите


## Користење на приклучоци за Fontawesome и/или Material Icons за прикажување на бесплатни икони во вашиот SRD

### Fontawesome

Користете Fontawesome за да добиете бесплатни и анимирани икони. Претплатените корисници можат да користат Pro икони.

1. Најдете ја иконата на [Fontawesome](https://fontawesome.com/icons)
2. Изберете ја иконата
3. Во скокачкиот прозорец, под табулаторот HTML, копирајте сè што е меѓу „ “

```EXAMPLE
<i class="fa-solid fa-dice-d20"></i>
```

4. Ставете го копираниот текст меѓу `:` без празни места

```EXAMPLE
fa-solid fa-dice-d20
```

### Material Icons

Користете Material Icons за повеќе бесплатни икони.

1. Најдете ги иконите на [Material Icons](https://fonts.google.com/icons)
2. Копирајте и вметнете ја web span врската директно во вашите markdown датотеки

```markup
<span class="material-icons">face</span>
```
