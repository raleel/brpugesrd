# د بنسټیز رول لوبولو نړیوال د لوبې انجن

د ORC منځپانګې سند

## کریډیټونه

د بنسټیز رول لوبولو (Basic Roleplaying) سیسټم پر بنسټ چې د سټیو پیرین، سټیو هینډرسن، وارن جیمز، ګریګ سټیفورډ، سینډي پیټرسن، رې ټرني، لین ویلیس لخوا رامینځته شوی.

**لیکوالان:** جیسن ډورال او سټیو پیرین

**تولیدونکی:** نیل رابینسن

**اضافي کریډیټونه:** داریا پیلارچیک، ریک مینټس، مایکل اوبرایان، او جیف ریچارډ

**ځانګړې مننه:** کین سینټ انډرې، کین آسټین، ویلیم بارټن، بل ډن، کین فینلیسن، مارک ایل ګیمبلر، سیم جانسن، ویلیم جونز، راډني لیري، بین مونرو، ګورډن مونسن، سارا نیوټن، سیم شیرلي، مارک موریسن، او ریچارډ واټس
