**Особая благодарность:** Кену Сент-Андре, Кену Остину, Уильяму Бартону, Биллу Данну, Кену Финлейсону, Марку Л. Гамблеру, Сэму Джонсону, Уильяму Джонсу, Родни Лири, Бену Монро, Гордону Монсону, Саре Ньютон, Сэму Ширли, Марку Моррисону и Ричарду Уоттсу
