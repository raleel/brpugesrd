# Предварительные требования

1. Базовое понимание [языка разметки markdown](https://www.markdownguide.org/basic-syntax/).

2. Вам потребуется создать бесплатную учетную запись на [github](https://github.com/), если у вас её еще нет. Рекомендую использовать название вашей НРИ, так как оно станет частью URL-адреса, по которому люди смогут получить доступ к вашему SRD. 

3. Вы можете выполнить весь этот процесс через браузер, не изучая git. Хотя освоение GitHub Desktop позволит вам тестировать любые изменения локально, прежде чем публиковать их для всеобщего обозрения.

> Если у вас зарегистрировано доменное имя, вы можете использовать его в этом процессе для создания SRD, как это сделал я: https://srd.7thextinctionrpg.com

# Процесс

## Создание репозитория на Github

1. Войдите в Github

2. Перейдите к публичному шаблону https://github.com/7thExtinctionrpg/RPG_SRD_Template

3. Нажмите "Use this template"

![Step3](/_media/Step3.png)

4. Выберите "Create a new repository"

5. Введите название репозитория

![Step5](/_media/Step5.png)

6. Выберите 'Private' 

7. Нажмите 'Create repository'

Копирование шаблона займет от 5 до 30 секунд, после чего у вас будет собственная копия.

8. Убедитесь, что у вас есть файл ".nojekyll" — это пустой файл, необходимый при размещении сайта на Github, иначе SRD будет отображаться некорректно. *(Указывает GitHub Pages не обрабатывать опубликованные файлы с помощью Jekyll).*


## Добавление вашего контента

### Файлы *.md

Файлы .md — это файлы markdown. Markdown — это облегченный язык разметки, который можно использовать для добавления элементов форматирования в обычные текстовые документы. В зависимости от объема контента вы можете либо разместить всю информацию о своей игре в одном файле *.md, либо, как я сделал на [7thextinctionrpg.com](https://srd.7thextinctionrpg.com), создать отдельные файлы для каждой главы. Файл "sample.md" содержит несколько примеров форматирования. 

Язык Markdown очень прост в освоении, используйте ссылку, указанную в пункте 2 раздела «Предварительные требования» выше, для получения полного списка синтаксиса. 

### _Sidebar.md

Это ваше меню, навигационная панель в левой части сайта. После того как вы добавили файл markdown в свой репозиторий, вам нужно добавить его сюда, чтобы его содержимое было включено в меню. Следуйте существующему формату.


## Включение Github Pages для превращения репозитория в веб-сайт

1. В своем репозитории нажмите на 'Settings'

![Website-Step1](/_media/Website-Step1.png)

2. Выберите 'Pages' в меню слева

![Website-Step2](/_media/Website-Step2.png)

3. Если вы не сделали репозиторий 'public', у вас есть два варианта:
    a. Сделать репозиторий публичным, что позволит вам использовать Github Pages для бесплатного размещения вашего сайта SRD
    b. Обновить учетную запись Github (на момент написания этого текста это стоит $4 в месяц или $48 в год)

4. В разделе 'Branch' выберите 'main' и нажмите 'save'

5. Подождите 10-20 секунд, затем обновите страницу

6. Теперь вы увидите свой URL, например https://coweater.github.io/mysrd/

![Website-Step6](/_media/Website-Step6.png)

3. Измените их на те шрифты, которые хотите использовать


## Использование плагина Fontawesome и/или Material Icons для отображения бесплатных иконок в вашем SRD

### Fontawesome

Используйте Fontawesome для получения бесплатных и анимированных иконок. Подписчики могут использовать Pro-иконки.

1. Найдите иконку на [Fontawesome](https://fontawesome.com/icons)
2. Выберите иконку
3. В открывшемся окне на вкладке HTML скопируйте все, что находится внутри " "

```EXAMPLE
<i class="fa-solid fa-dice-d20"></i>
```

4. Поместите скопированный текст между `:` без пробелов

```EXAMPLE
fa-solid fa-dice-d20
```

### Material Icons

Используйте Material Icons для получения еще большего количества бесплатных иконок.

1. Найдите иконки на [Material Icons](https://fonts.google.com/icons)
2. Скопируйте и вставьте веб-ссылку span непосредственно в ваши файлы markdown

```markup
<span class="material-icons">face</span>
```
