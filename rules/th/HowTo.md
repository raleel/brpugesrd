# ข้อกำหนดเบื้องต้น

1. ความเข้าใจพื้นฐานเกี่ยวกับ [ภาษา markdown](https://www.markdownguide.org/basic-syntax/)

2. คุณจะต้องสร้างบัญชี [github](https://github.com/) ฟรีหากคุณยังไม่มี ขอแนะนำให้ใช้ชื่อเกม RPG ของคุณเนื่องจากจะกลายเป็นส่วนหนึ่งของ URL ที่ผู้คนจะใช้เข้าถึง SRD ของคุณ

3. คุณสามารถดำเนินการทั้งหมดนี้ผ่านเบราว์เซอร์ได้โดยไม่ต้องมีความรู้เรื่อง git แม้ว่าการเรียนรู้ github desktop จะช่วยให้คุณทดสอบการเปลี่ยนแปลงใดๆ ในเครื่องได้ก่อนที่จะเผยแพร่จริงเพื่อให้คนทั้งโลกได้เห็นก็ตาม

> หากคุณมีชื่อโดเมนที่จดทะเบียนไว้ คุณสามารถใช้ชื่อนั้นกับกระบวนการนี้เพื่อสร้าง SRD เหมือนกับที่ฉันทำ https://srd.7thextinctionrpg.com

# กระบวนการ

## การสร้าง Repository บน Github

1. เข้าสู่ระบบ Github

2. ไปที่เทมเพลตสาธารณะ https://github.com/7thExtinctionrpg/RPG_SRD_Template

3. คลิก "Use this template"

![Step3](/_media/Step3.png)

4. เลือก "Create a new repository"

5. ใส่ชื่อ repository

![Step5](/_media/Step5.png)

6. เลือก 'Private'

7. เลือก 'Create repository'

ระบบจะใช้เวลา 5-30 วินาทีในการคัดลอกเทมเพลต จากนั้นคุณจะมีสำเนาเป็นของตัวเอง

8. ตรวจสอบให้แน่ใจว่าคุณมีไฟล์ ".nojekyll" ซึ่งเป็นไฟล์เปล่าที่จำเป็นเมื่อโฮสต์เว็บไซต์บน Github มิฉะนั้น SRD จะแสดงผลไม่ถูกต้อง *(บอกให้ GitHub Pages ไม่ต้องรันไฟล์ที่เผยแพร่ผ่าน Jekyll)*


## การเพิ่มเนื้อหาของคุณ

### ไฟล์ *.md

ไฟล์ .md คือไฟล์ markdown ซึ่ง Markdown เป็นภาษามาร์กอัปน้ำหนักเบาที่คุณสามารถใช้เพื่อเพิ่มองค์ประกอบการจัดรูปแบบให้กับเอกสารข้อความธรรมดาได้ ขึ้นอยู่กับขนาดของเนื้อหาของคุณ คุณสามารถวางข้อมูลเกมทั้งหมดไว้ในไฟล์ *.md ไฟล์เดียว หรือสร้างไฟล์แยกต่างหากสำหรับแต่ละบทเหมือนที่ฉันทำที่ [7thextinctionrpg.com](https://srd.7thextinctionrpg.com) โดย "sample.md" ได้ให้ตัวอย่างการจัดรูปแบบไว้บางส่วน

ภาษา Markdown นั้นเรียนรู้ได้ง่ายมาก ใช้ลิงก์ที่ให้ไว้ในข้อ 2 ภายใต้ข้อกำหนดเบื้องต้นด้านบนเพื่อดูรายการไวยากรณ์ทั้งหมด

### _Sidebar.md

นี่คือเมนูหรือบานหน้าต่างการนำทางที่ด้านซ้ายของเว็บไซต์ เมื่อคุณเพิ่มไฟล์ markdown ลงใน repository ของคุณแล้ว คุณต้องเพิ่มไฟล์ที่นี่เพื่อให้เนื้อหาถูกรวมไว้ด้วย ปฏิบัติตามรูปแบบที่มีอยู่เดิม


## การเปิดใช้งาน Github Pages เพื่อเปลี่ยน Repository ให้เป็นเว็บไซต์

1. ใน repository ของคุณ ให้คลิกที่ 'Settings'

![Website-Step1](/_media/Website-Step1.png)

2. เลือก 'Pages' ในเมนูด้านซ้ายมือ

![Website-Step2](/_media/Website-Step2.png)

3. หากคุณยังไม่ได้ตั้งค่า repository ให้เป็น 'public' คุณมีสองทางเลือก:
    a. ทำให้ repository เป็นสาธารณะ (public) ซึ่งจะช่วยให้คุณใช้ Github pages เพื่อโฮสต์เว็บไซต์ SRD ของคุณได้ฟรี
    b. อัปเกรดบัญชี Github ของคุณ (ณ เวลาที่เขียนนี้ มีค่าใช้จ่าย 4 ดอลลาร์ต่อเดือน หรือค่าธรรมเนียมรายปี 48 ดอลลาร์)

4. ภายใต้ 'Branch' ให้เลือก 'main' และคลิกบันทึก

5. รอ 10-20 วินาทีแล้วรีเฟรชหน้าเว็บ

6. ตอนนี้คุณจะเห็น URL ของคุณ เช่น https://coweater.github.io/mysrd/

![Website-Step6](/_media/Website-Step6.png)

## การใช้ปลั๊กอิน Fontawesome และ/หรือ Material Icons เพื่อแสดงไอคอนฟรีใน SRD ของคุณ

### Fontawesome

ใช้ Fontawesome เพื่อรับไอคอนฟรีและไอคอนแบบเคลื่อนไหว ผู้ใช้แบบสมัครสมาชิกสามารถใช้ Pro Icons ได้

1. ค้นหาไอคอนบน [Fontawesome](https://fontawesome.com/icons)
2. เลือกไอคอน
3. ในหน้าต่างป๊อปอัป ใต้แท็บ HTML ให้คัดลอกทุกอย่างระหว่าง " "

```EXAMPLE
<i ชนชั้น="fa-solid fa-dice-d20"></i>
```

4. วางข้อความที่คัดลอกไว้ระหว่าง `:` โดยไม่มีช่องว่าง

```EXAMPLE
fa-solid fa-dice-d20
```

### Material Icons

ใช้ Material Icons สำหรับไอคอนฟรีเพิ่มเติม

1. ค้นหาไอคอนบน [Material Icons](https://fonts.google.com/icons)
2. คัดลอก & แทรกเว็บลิงก์ span ลงในไฟล์ markdown ของคุณโดยตรง

```markup
<span ชนชั้น="material-icons">face</span>
```
