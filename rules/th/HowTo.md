# ข้อกำหนดเบื้องต้น

1. ความเข้าใจพื้นฐานเกี่ยวกับ [ภาษา Markdown](https://www.markdownguide.org/basic-syntax/)

2. คุณจำเป็นต้องสร้างบัญชี [github](https://github.com/) แบบฟรี หากคุณยังไม่มี แนะนำให้ใช้ชื่อเกม RPG ของคุณเนื่องจากชื่อนี้จะกลายเป็นส่วนหนึ่งของ URL ที่ผู้คนใช้เข้าถึง SRD ของคุณ

3. คุณสามารถทำกระบวนการทั้งหมดนี้ผ่านเบราว์เซอร์ได้โดยไม่ต้องมีความรู้เรื่อง git แม้ว่าการเรียนรู้การใช้งาน Github Desktop จะช่วยให้คุณสามารถทดสอบการเปลี่ยนแปลงต่างๆ ในเครื่องก่อนที่จะเผยแพร่จริงให้โลกเห็นได้ก็ตาม

> หากคุณมีชื่อโดเมนที่จดทะเบียนไว้ คุณสามารถใช้ชื่อโดเมนนั้นร่วมกับกระบวนการนี้เพื่อสร้าง SRD เหมือนกับที่ผมทำที่ https://srd.7thextinctionrpg.com

## การเพิ่มเนื้อหาของคุณ

### ไฟล์ *.md

ไฟล์ .md คือไฟล์ Markdown ซึ่งเป็นภาษา Markup แบบน้ำหนักเบาที่คุณสามารถใช้เพื่อเพิ่มองค์ประกอบการจัดรูปแบบให้กับเอกสารข้อความธรรมดา ขึ้นอยู่กับขนาดของเนื้อหา คุณสามารถวางข้อมูลเกมทั้งหมดไว้ในไฟล์ *.md ไฟล์เดียว หรือจะสร้างไฟล์แยกสำหรับแต่ละบทเหมือนที่ผมทำที่ [7thextinctionrpg.com](https://srd.7thextinctionrpg.com) ก็ได้ ไฟล์ "sample.md" มีตัวอย่างการจัดรูปแบบให้ดู

ภาษา Markdown นั้นเรียนรู้ได้ง่ายมาก โปรดใช้ลิงก์ที่ให้ไว้ในข้อ 2 ภายใต้หัวข้อข้อกำหนดเบื้องต้นด้านบนเพื่อดูรายการไวยากรณ์ทั้งหมด

### _Sidebar.md

นี่คือเมนูหรือบานหน้าต่างนำทางทางด้านซ้ายของเว็บไซต์ เมื่อคุณเพิ่มไฟล์ Markdown ลงใน Repository ของคุณแล้ว คุณต้องเพิ่มไฟล์ดังกล่าวที่นี่เพื่อให้เนื้อหาถูกรวมเข้าไปด้วย ให้ทำตามรูปแบบการจัดวางที่มีอยู่เดิม

## การเปิดใช้งาน Github Pages เพื่อเปลี่ยน Repository ให้เป็นเว็บไซต์

1. ใน Repository ของคุณ ให้คลิกที่ 'Settings'

![Website-Step1](/_media/Website-Step1.png)

2. เลือก 'Pages' บนเมนูด้านซ้ายมือ

![Website-Step2](/_media/Website-Step2.png)

3. หากคุณยังไม่ได้ตั้งค่า Repository เป็น 'public' คุณมีสองทางเลือก:
    a. ทำให้ Repository เป็นสาธารณะ (public) ซึ่งจะช่วยให้คุณใช้ Github Pages เพื่อโฮสต์เว็บไซต์ SRD ของคุณได้ฟรี
    b. อัปเกรดบัญชี Github ของคุณ (ณ เวลาที่เขียนบทความนี้ มีค่าใช้จ่าย $4 ต่อเดือน หรือ $48 ต่อปี)

4. ภายใต้หัวข้อ 'Branch' ให้เลือก 'main' แล้วคลิก Save

5. รอประมาณ 10-20 วินาทีแล้วรีเฟรชหน้าเว็บ

6. คุณจะเห็น URL ของคุณ เช่น https://coweater.github.io/mysrd/

![Website-Step6](/_media/Website-Step6.png)

## การใช้ปลั๊กอิน Fontawesome และ/หรือ Material Icons เพื่อแสดงไอคอนฟรีใน SRD ของคุณ

### Fontawesome

ใช้ Fontawesome เพื่อรับไอคอนฟรีและไอคอนแบบเคลื่อนไหว ผู้ใช้ที่สมัครสมาชิกสามารถใช้ Pro Icons ได้

1. ค้นหาไอคอนที่ [Fontawesome](https://fontawesome.com/icons)
2. เลือกไอคอน
3. ในหน้าต่างป๊อปอัป ภายใต้แท็บ HTML ให้คัดลอกทุกอย่างระหว่าง " "

```EXAMPLE
<i class="fa-solid fa-dice-d20"></i>
```

4. วางข้อความที่คัดลอกมาระหว่าง `:` โดยไม่มีเว้นวรรค

```EXAMPLE
fa-solid fa-dice-d20
```

### Material Icons

ใช้ Material Icons เพื่อรับไอคอนฟรีเพิ่มเติม

1. ค้นหาไอคอนที่ [Material Icons](https://fonts.google.com/icons)
2. คัดลอกและแทรกลิงก์ span ของเว็บลงในไฟล์ Markdown ของคุณโดยตรง

```markup
<span class="material-icons">face</span>
```
