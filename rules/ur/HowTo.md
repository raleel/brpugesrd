# پیشگی شرائط

1. [markdown language](https://www.markdownguide.org/basic-syntax/) کی بنیادی سمجھ۔

2. اگر آپ کا [github](https://github.com/) اکاؤنٹ نہیں ہے تو آپ کو ایک مفت اکاؤنٹ بنانا ہوگا۔ تجویز ہے کہ آپ اپنے آر پی جی (RPG) کا نام استعمال کریں کیونکہ یہ اس یو آر ایل (URL) کا حصہ بن جائے گا جسے لوگ آپ کے SRD تک رسائی کے لیے استعمال کریں گے۔

3. آپ یہ سارا عمل گٹ (git) جانے بغیر براؤزر کے ذریعے کر سکتے ہیں۔ اگرچہ github desktop سیکھنے سے آپ کو لائیو پبلش کرنے سے پہلے مقامی طور پر کسی بھی تبدیلی کو ٹیسٹ کرنے کی سہولت ملے گی۔

> اگر آپ کے پاس رجسٹرڈ ڈومین نام ہے، تو آپ اسے اس عمل کے ساتھ استعمال کر سکتے ہیں تاکہ میرے جیسا SRD بنا سکیں https://srd.7thextinctionrpg.com

# عمل

## Github پر ریپوزٹری (Repository) بنانا

1. Github پر لاگ ان کریں

2. عوامی ٹیمپلیٹ https://github.com/7thExtinctionrpg/RPG_SRD_Template پر جائیں

3. "Use this template" پر کلک کریں

![Step3](/_media/Step3.png)

4. "Create a new repository" منتخب کریں

5. ریپوزٹری کا نام درج کریں

![Step5](/_media/Step5.png)

6. 'Private' منتخب کریں

7. 'Create repository' منتخب کریں

ٹیمپلیٹ کاپی کرنے میں 5-30 سیکنڈ لگیں گے، اس کے بعد آپ کے پاس اپنی کاپی موجود ہوگی۔

8. یقینی بنائیں کہ آپ کے پاس ".nojekyll" فائل موجود ہے، یہ ایک خالی فائل ہے جو Github پر ویب سائٹ ہوسٹ کرتے وقت درکار ہوتی ہے، بصورت دیگر SRD صحیح طریقے سے ظاہر نہیں ہوگا۔ *(یہ GitHub Pages کو بتاتا ہے کہ شائع شدہ فائلوں کو Jekyll کے ذریعے نہ چلایا جائے)۔*


## اپنا مواد شامل کرنا

### *.md فائلیں

.md فائلیں مارک ڈاؤن فائلیں ہوتی ہیں۔ مارک ڈاؤن ایک ہلکی مارک اپ زبان ہے جسے آپ سادہ ٹیکسٹ دستاویزات میں فارمیٹنگ کے عناصر شامل کرنے کے لیے استعمال کر سکتے ہیں۔ اپنے مواد کے سائز کے لحاظ سے، آپ اپنے گیم کی تمام معلومات کو ایک ہی *.md فائل میں رکھ سکتے ہیں، یا جیسا کہ میں نے [7thextinctionrpg.com](https://srd.7thextinctionrpg.com) پر کیا ہے، ہر باب کے لیے الگ الگ فائلیں بنا سکتے ہیں۔ "sample.md" کچھ فارمیٹنگ کی مثالیں فراہم کرتا ہے۔

مارک ڈاؤن زبان سیکھنے میں بہت آسان ہے، مکمل সিনٹیکس کی فہرست کے لیے اوپر دی گئی پیشگی شرائط کے پوائنٹ 2 میں فراہم کردہ لنک کا استعمال کریں۔

### _Sidebar.md

1. اپنی ریپوزٹری میں 'Settings' پر کلک کریں

![Website-Step1](/_media/Website-Step1.png)

2. بائیں جانب والے مینو میں 'Pages' منتخب کریں

## اپنے SRD میں مفت آئیکنز دکھانے کے لیے Fontawesome اور/یا Material Icons پلگ ان کا استعمال

### Fontawesome

مفت آئیکنز اور اینی میٹڈ آئیکنز حاصل کرنے کے لیے Fontawesome کا استعمال کریں۔ سبسکرائب شدہ صارفین پرو آئیکنز استعمال کر سکتے ہیں۔

1. [Fontawesome](https://fontawesome.com/icons) پر آئیکن تلاش کریں
2. آئیکن منتخب کریں
3. پاپ اپ ونڈو میں، HTML ٹیب کے تحت " " کے درمیان موجود ہر چیز کو کاپی کریں

```EXAMPLE
<i class="fa-solid fa-dice-d20"></i>
```

4. کاپی کیے گئے ٹیکسٹ کو `:` کے درمیان رکھیں، کوئی اسپیس نہ دیں۔

```EXAMPLE
fa-solid fa-dice-d20
```

### Material Icons

مزید مفت آئیکنز کے لیے Material Icons کا استعمال کریں

1. [Material Icons](https://fonts.google.com/icons) پر آئیکنز تلاش کریں
2. ویب اسپین لنک کو کاپی کریں اور براہ راست اپنی مارک ڈاؤن فائلوں میں داخل کریں

```markup
<span class="material-icons">face</span>
```
