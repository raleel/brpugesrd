# BR:UGE

#### Basic Roleplaying: Universal Game Engine

###### ORC مواد کی دستاویز

## کریڈٹ

یہ سٹیو پیرن، سٹیو ہینڈرسن، وارن جیمز، گریگ سٹیفورڈ، سینڈی پیٹرسن، رے ٹرنی، اور لن ولیس کے تخلیق کردہ Basic Roleplaying سسٹم پر مبنی ہے۔

**مصنفین:** جیسن ڈورل اور سٹیو پیرن

**پروڈیوسر:** نیل رابنسن

**اضافی کریڈٹ:** ڈاریا پیلارزک، رک مینٹس، مائیکل اوبرائن، اور جیف رچرڈ

**خصوصی شکریہ:** کین سینٹ آندرے، کین آسٹن، ولیم بارٹن، بل ڈن، کین فنلیسن، مارک ایل گیمبلر، سیم جانسن، ولیم جونز، روڈنی لیری، بین منرو، گورڈن مونسن، سارہ نیوٹن، سیم شرلی، مارک موریسن، اور رچرڈ واٹس۔
