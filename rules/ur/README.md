## کریڈٹس

یہ اسٹیو پیرن، اسٹیو ہینڈرسن، وارن جیمز، گریگ اسٹافورڈ، سینڈی پیٹرسن، رے ٹرنی، اور لن ولِس کے تخلیق کردہ بنیادی رول پلیئنگ (Basic Roleplaying) سسٹم پر مبنی ہے۔

**مصنفین:** جیسن ڈیورل اور اسٹیو پیرن

**پروڈیوسر:** نیل رابنسن

**اضافی کریڈٹس:** ڈاریا پیلارزک، رک مینٹس، مائیکل اوبرائن، اور جیف رچرڈ

**خصوصی شکریہ:** کین سینٹ آندرے، کین آسٹن، ولیم بارٹن، بل ڈن، کین فنلیسن، مارک ایل گیمبلر، سیم جانسن، ولیم جونز، روڈنی لیری، بین منرو، گورڈن مونسن، سارہ نیوٹن، سیم شرلی، مارک موریسن، اور رچرڈ واٹس
