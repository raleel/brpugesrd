# موتور بازی جهانی نقش‌آفرینی پایه (Basic Roleplaying)

سند محتوای ORC

## دست‌اندرکاران

بر اساس سیستم نقش‌آفرینی پایه (Basic Roleplaying) که توسط استیو پرین، استیو هندرسون، وارن جیمز، گرگ استفورد، سندی پیترسن، ری ترنی، و لین ویلیس خلق شده است.

**نویسندگان:** جیسون دورال و استیو پرین

**تهیه‌کننده:** نیل رابینسون

**سایر دست‌اندرکاران:** داریا پیلارچیک، ریک مینتس، مایکل اوبراین و جف ریچارد

**تشکر ویژه:** کن سنت آندره، کن آستین، ویلیام بارتون، بیل دان، کن فینلیسون، مارک ال. گمبلر، سم جانسون، ویلیام جونز، رادنی لیری، بن مونرو، گوردون مونسون، سارا نیوتن، سم شرلی، مارک موریسون، و ریچارد واتس
