# BR:UGE

#### Basic Roleplaying: Universal Game Engine

###### مستند محتوای ORC

## اعتبارنامه‌ها

بر اساس سیستم Basic Roleplaying که توسط استیو پرین، استیو هندرسون، وارن جیمز، گرگ استافورد، سندی پیترسن، ری ترنی، لین ویلیس خلق شده است.

**نویسندگان:** جیسون دورال و استیو پرین

**تهیه‌کننده:** نیل رابینسون

**اعتبارنامه‌های تکمیلی:** داریا پیلارچیک، ریک مینتز، مایکل اوبرایان و جف ریچارد

**تشکر ویژه:** کن سنت آندره، کن آستین، ویلیام بارتون، بیل دان، کن فینلیسون، مارک ال. گامبلر، سم جانسون، ویلیام جونز، رادنی لیری، بن مونرو، گوردون مونسون، سارا نیوتون، سم شرلی، مارک موریسون و ریچارد واتس
